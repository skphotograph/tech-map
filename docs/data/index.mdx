# データ

注文や利用者の情報を保存するだけなら、ファイルにも書けます。  
しかし、複数の処理から安全に読み書きし、大量のデータを探し、システム間で変更を届けるには、用途に合った仕組みが必要です。

このカテゴリでは、表と関係でデータを管理する RDB、データの形や読み書きの要件に合わせて選ぶ NoSQL、システム間で情報を受け渡すメッセージングを扱います。  
データの置き場所と渡し方を、要件に合わせて選ぶための土台を作ります。
