# SQL / RDB をはじめよう

この章では、表と関係でデータを管理する **リレーショナルデータベース（RDB）** と、それを操作する言語 **SQL** を学びます。  
例は主に **PostgreSQL** で示します。構文の多くはほかの RDB でも通じますが、型名・関数・接続方法は製品差があります。

## この章で分かること

- RDB が解決する課題（複数処理からの安全な読み書き、条件での検索）
- 表・行・列・主キー・外部キーの考え方
- `SELECT` / `JOIN` / 集計と、追加・更新・削除の基本
- トランザクションとインデックスの実務上の意味

## こんな場面で効く

注文一覧は出るのに、特定の注文番号だけ探すと遅い。  
在庫を減らしたあと決済が失敗して、在庫だけ減ったまま残る。  
「どのユーザーがどの注文を持つか」をファイルや表計算ソフトで追うと、コピーが散らかってどれが正か分からない。

RDB と SQL は、こうした **保存・検索・一貫した更新** を、複数のプログラムから共通のルールで扱うための土台です。  
アプリのフレームワークを使っていても、障害調査や性能確認では発行 SQL を読む場面が出てきます。

:::tip[この章のゴール]

小さな注文・利用者の表を想定し、必要な行を取り出し、関係を結合し、更新をまとめて確定／取り消せる状態を目指します。

:::
