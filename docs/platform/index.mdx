# DevOps / コンテナ

「手元では動いたのに、サーバでは動かない」「リリースのたびに手順や結果が変わる」。  
開発環境と運用環境の差や、手作業に依存したリリースは、変更を届ける速度と安全性を下げます。

このカテゴリでは、アプリの実行環境をそろえるコンテナと、変更を継続的に届ける仕組みを扱います。  
Docker から運用基盤、CI/CD、IaC まで、同じ構成と手順を再現できる状態を目指します。
