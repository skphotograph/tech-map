# 配列

注文が 1 件なら、ひとつの変数で足ります。  
10 件、100 件と増えたときに `order1`、`order2` と変数を増やしていては、数えることも順番に処理することも大変です。  
JavaScript の **配列** を使うと、複数の値を順番付きの一覧として扱えます。

[オブジェクト](./objects) の `Object.keys` も配列を返していました。  
ここでは、配列そのものの読み書きと、コールバックを渡すメソッドを学びます。

## このページで分かること

- 配列を作り、添字と `length` で要素を読む
- 元の配列を変える操作と、新しい配列を返す操作の違い
- `for...of` と `includes` / `slice` / `join` / `split` との連携
- `forEach` で各要素にコールバックを渡す
- `some` / `every` / `reduce` の使いどころ
- `map` / `filter` / `find` を目的で選ぶ

## 配列は「順番付きの一覧」

配列は、値を決まった順番で並べたものです。  
角括弧 `[]` の中に、要素をカンマで区切って書きます。

```js
const statuses = ['OPEN', 'PAID', 'SHIPPED'];
```

配列の位置を表す番号を **添字（インデックス）** と呼びます。  
JavaScript の添字は `0` から始まります。

```js
console.log(statuses[0]); // OPEN
console.log(statuses[1]); // PAID
console.log(statuses[2]); // SHIPPED
```

存在しない位置を読むと、エラーではなく `undefined` になります。

```js
console.log(statuses[3]); // undefined
```

要素数は `length` で分かります。

```js
console.log(statuses.length); // 3
```

:::tip[添字と要素数]

要素数は `length`、有効な添字は `0` から `length - 1` までです。

:::

## 元の配列を変える操作

`push` と `pop` は、**元の配列そのもの** を更新します。

```js
const orderIds = ['ORD-1001', 'ORD-1002'];

orderIds.push('ORD-1003');

console.log(orderIds);
// [ 'ORD-1001', 'ORD-1002', 'ORD-1003' ]
```

末尾以外を変える代表例です。

| メソッド  | 動き                       |
| --------- | -------------------------- |
| `unshift` | 先頭に追加                 |
| `shift`   | 先頭を取り除いて返す       |
| `splice`  | 途中の要素を削除・差し替え |

```js
const queue = ['B', 'C'];
queue.unshift('A');
console.log(queue); // [ 'A', 'B', 'C' ]
```

`const` で宣言した配列でも、`push` などで **中身** は変えられます。  
[オブジェクト](./objects) と同様、`const` が防ぐのは変数そのものへの再代入です。

:::warning[破壊的変更]

`push` / `pop` / `splice` は元の配列を書き換えます。  
共有している別の変数から見ても中身が変わるため、意図をコメントや変数名で残すと安全です。

:::

## 新しい配列を返す操作

`slice` は、指定範囲を **コピーした新しい配列** を返します。元の配列は変わりません。

```js
const statuses = ['OPEN', 'PAID', 'SHIPPED'];
const firstTwo = statuses.slice(0, 2);

console.log(firstTwo); // [ 'OPEN', 'PAID' ]
console.log(statuses.length); // 3
```

[文字列とテキスト](./strings-and-text) の `slice` と同様、終了位置は **含みません**。

要素が含まれるか調べる `includes`、配列を文字列へつなぐ `join` も非破壊です。

```js
console.log(statuses.includes('PAID')); // true
console.log(statuses.join(' → ')); // OPEN → PAID → SHIPPED
```

カンマ区切りの一行テキストを配列へ分けるときは、文字列の `split` を使います。

```js
const line = 'OPEN,PAID,SHIPPED';
const statusesFromText = line.split(',');

console.log(statusesFromText);
// [ 'OPEN', 'PAID', 'SHIPPED' ]
```

`split` で作った配列は、上で学んだ `includes` や `join` と組み合わせられます。

```js
console.log(statusesFromText.join(' / ')); // OPEN / PAID / SHIPPED
```

## `for...of` で順番に読む

すべての要素を先頭から処理したいときは、`for...of` が読みやすい書き方です。  
[繰り返し](./loops) の `for` がカウンタ中心なのに対し、ここでは **各要素そのもの** を取り出します。

```js
const orderIds = ['ORD-1001', 'ORD-1002', 'ORD-1003'];

for (const orderId of orderIds) {
  console.log(orderId);
}
```

```text
ORD-1001
ORD-1002
ORD-1003
```

`for (const orderId of orderIds)` の `orderId` は、`for` ループの `{ ... }` の中だけ有効です。  
[スコープと変数の有効範囲](./scope-and-variables) で学んだブロックスコープと同じ考え方です。

添字が必要なときは、古典的な `for` も使えます。

```js
for (let i = 0; i < orderIds.length; i++) {
  console.log(`${i}: ${orderIds[i]}`);
}
```

## `forEach` で各要素に処理を渡す

[関数](./functions) で学んだ **コールバック** を、配列の各要素へ渡す代表例が `forEach` です。

```js
const orderIds = ['ORD-1001', 'ORD-1002'];

orderIds.forEach((orderId) => {
  console.log(orderId);
});
```

```text
ORD-1001
ORD-1002
```

`forEach` に渡した関数は、要素が存在するたびに呼ばれます。  
**戻り値は使いません**（`forEach` 自体の結果は `undefined` です）。

[オブジェクト](./objects) の `Object.keys` の結果を回すときも、同じ考え方で `forEach` を使えます。

```js
const order = { id: 'ORD-1001', status: 'OPEN' };

Object.keys(order).forEach((key) => {
  console.log(`${key}: ${order[key]}`);
});
```

:::tip[forEach の位置づけ]

表示や記録のように「各要素に副作用を起こす」処理向きです。新しい配列が欲しいときは `map` を使います。

:::

## `some` と `every` で条件を調べる

「条件に合う要素が **ひとつでも** あるか」は `some`、「**すべて** 合うか」は `every` です。

```js
const amounts = [800, 1200, 1500];

console.log(amounts.some((amount) => amount >= 1000)); // true
console.log(amounts.every((amount) => amount >= 1000)); // false
```

どちらも **true / false** を返し、新しい配列は作りません。

## `reduce` で一覧をひとつの値に畳む

合計や件数のように、配列全体から **ひとつの結果** を作るときは `reduce` を使います。

```js
const amounts = [800, 1200, 1500];

const total = amounts.reduce((sum, amount) => sum + amount, 0);

console.log(total); // 3500
```

第 2 引数の `0` は **初期値** です。  
`reduce` に渡す関数は `(これまでの結果, いまの要素)` を受け取り、次の要素へ渡す値を返します。

## `map` / `filter` / `find` — 新しい配列や要素を返す

[関数](./functions) で学んだ **コールバック** を渡す代表例です。  
いずれも **元の配列は変更しません**（非破壊）。

### `map` — 各要素を変換

```js
const orders = [
  { id: 'ORD-1001', status: 'OPEN' },
  { id: 'ORD-1002', status: 'PAID' },
  { id: 'ORD-1003', status: 'OPEN' },
];

const orderIds = orders.map((order) => order.id);

console.log(orderIds);
// [ 'ORD-1001', 'ORD-1002', 'ORD-1003' ]
```

### `filter` — 条件に合う要素だけ

```js
const openOrders = orders.filter((order) => order.status === 'OPEN');

console.log(openOrders.length); // 2
```

### `find` — 最初の一致をひとつ

```js
const paidOrder = orders.find((order) => order.status === 'PAID');

console.log(paidOrder.id); // ORD-1002
```

| 欲しい結果                 | メソッド  | 元の配列   | 戻り値                         |
| -------------------------- | --------- | ---------- | ------------------------------ |
| 全要素を別の形にする       | `map`     | そのまま   | 同じ要素数の新しい配列         |
| 条件に合う要素だけ残す     | `filter`  | そのまま   | 0 件以上の新しい配列           |
| 条件に合う要素をひとつ探す | `find`    | そのまま   | 最初の要素、または `undefined` |
| 合計・集計                 | `reduce`  | そのまま   | 畳み込んだ単一の値             |
| 末尾の追加・削除           | `push` 等 | **変わる** | 長さや取り出した要素など       |

:::tip[破壊的かどうかを先に見る]

`push` / `splice` は元を変える。`map` / `filter` / `slice` は新しい結果を返す。

:::

## よくあるつまずき

- 先頭の添字を `1` だと思い、ひとつ後ろの要素を読む
- `push` と `slice` を混同し、どちらが元を変えるか見落とす
- `find` の結果が見つからない場合の `undefined` を考慮しない
- `map` の戻り値を受け取らず、元の配列が変わると思い込む
- `reduce` の初期値を省略し、意図しない型から始める
- `forEach` の戻り値を配列だと思い込む
- ひとつ探せばよい場面で `filter` を使い、配列と単一要素を混同する

## まとめ / 次に学ぶとよいこと

- 配列は順番付きの一覧で、添字は `0` から始まる
- `push` / `pop` / `splice` は元の配列を変える
- `slice` / `map` / `filter` / `find` / `reduce` は新しい結果を返す
- `for...of` で各要素を、`forEach` でコールバックを要素ごとに呼び出す
- `includes` / `join` / `split` で一覧と文字列を行き来する
- `some` / `every` で条件の存在・全称を調べる
- `reduce` で合計のように一覧をひとつの値へ畳める
