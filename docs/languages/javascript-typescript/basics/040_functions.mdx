# 関数

同じ計算を何か所にもコピーすると、変更時に一つだけ直し忘れることがあります。  
まとまった処理に名前を付け、必要な場所から呼び出せるようにしたものが **関数** です。

[繰り返し](./loops) でその場に書いた処理を繰り返す代わりに、関数にして呼び出すと重複を減らせます。

## このページで分かること

- 関数を定義して呼び出す方法
- 引数と戻り値の役割
- 戻り値が無い関数と早期 `return`
- アロー関数という現代的な書き方
- 関数を値として渡す方法（コールバック）

## 関数は「名前の付いた手順」

二つの数を足す手順に `add` という名前を付けます。

```js
function add(a, b) {
  return a + b;
}

const total = add(2, 3);
console.log(total); // 5
```

| 部分           | 役割                           |
| -------------- | ------------------------------ |
| `function`     | 関数を定義する印               |
| `add`          | 関数の名前                     |
| `(a, b)`       | 関数が受け取る値の置き場所     |
| `{ ... }`      | 呼び出されたときに実行する処理 |
| `return a + b` | 結果を呼び出し元へ返す         |
| `add(2, 3)`    | 関数を呼び出す                 |

関数を定義しただけでは、本体は実行されません。  
`add(2, 3)` のように呼び出して、初めて波括弧の中が動きます。

:::tip[関数の基本]

関数は処理を定義し、`関数名(...)` で呼び出します。  
`return` した値は、呼び出した場所で使えます。

:::

## 仮引数と引数

関数側の `a` と `b` は **仮引数（パラメータ）**、呼び出し側の `2` と `3` は **引数** です。

```js
function createLabel(orderId, status) {
  return `${orderId}: ${status}`;
}

const label = createLabel('ORD-1001', 'PAID');
console.log(label); // ORD-1001: PAID
```

引数は左から順に仮引数へ渡されます。  
この例では、`orderId` に `"ORD-1001"`、`status` に `"PAID"` が入ります。

JavaScript は、引数の個数が定義と違っても呼び出し自体を許します。  
足りない仮引数には `undefined` が入り、余分な引数は通常使われません。  
意図しない結果を避けるため、呼び出し側と定義側の個数を揃えます。

## `return` で結果を返す

`return` には二つの働きがあります。

1. 値を呼び出し元へ返す
2. その時点で関数の実行を終える

```js
function calculatePrice(unitPrice, quantity) {
  const subtotal = unitPrice * quantity;
  return subtotal;
  console.log('ここは実行されない');
}
```

`return` より後ろの文は実行されません。  
返された値は、変数への代入だけでなく、別の式や関数呼び出しにも使えます。

```js
console.log(calculatePrice(1200, 2)); // 2400
```

## 戻り値が無い関数

表示や記録だけを行い、計算結果を返す必要がない関数もあります。

```js
function printStatus(status) {
  console.log(`status: ${status}`);
}

printStatus('PAID');
```

```text
status: PAID
```

JavaScript では、戻り値が無いことを示す `void` を関数宣言に書きません。  
`return` を書かなかった関数を呼び出すと、呼び出し結果は `undefined` になります。

```js
const result = printStatus('PAID');
console.log(result); // undefined
```

## 早期 `return` で入口を整理する

条件分岐が何段も重なると、主要な処理が奥へ押し込まれます。  
処理できない条件を関数の入口で返す **早期 `return`** を使うと、流れを平らにできます。

```js
function getOrderLabel(amount) {
  if (amount < 0) {
    return 'invalid';
  }

  if (amount >= 1000) {
    return 'bulk';
  }

  return 'normal';
}

console.log(getOrderLabel(1200)); // bulk
console.log(getOrderLabel(-1)); // invalid
```

負の金額なら、その時点で `"invalid"` を返して関数を終えます。  
後ろの処理は、有効な金額だけを考えればよくなります。

値を返さず、その場で関数を終える `return;` も使えます。

```js
function printOrder(orderId) {
  if (orderId === undefined) {
    return;
  }

  console.log(`order-${orderId}`);
}
```

## アロー関数

JavaScript のコードでは、関数を値として `const` へ入れる **アロー関数** もよく見かけます。  
短い処理をその場で定義するときに、`function` を繰り返さず簡潔に書けることが利点です。

```js
const add = (a, b) => {
  return a + b;
};

console.log(add(2, 3)); // 5
```

処理が式一つだけなら、波括弧と `return` を省略できます。

```js
const add = (a, b) => a + b;
const isLarge = (amount) => amount >= 1000;
```

`=>` の右側にある式の結果が、そのまま戻り値になります。  
波括弧を付けた場合は、自動では返らないため `return` が必要です。

```js
const add = (a, b) => {
  return a + b;
};
```

どちらも呼び出せる関数を作るため、アロー関数が常に優れているわけではありません。  
この教材では、処理に名前を付けて独立して再利用するなら `function`、短い関数を変数へ入れるならアロー関数、という基準から始めます。既存のコードでは周囲の書き方も確認し、同じ役割の関数で形式をそろえると読みやすくなります。

## JavaScript の関数名と引数

JavaScript では、引数の個数や種類だけを変えて、同じ名前の関数を複数定義する **シグネチャによるオーバーロード** はできません。

```js
function formatOrderLine(name) {
  return `${name} x1`;
}

function formatOrderLine(name, quantity) {
  return `${name} x${quantity}`;
}

console.log(formatOrderLine('mug')); // mug xundefined
```

後から書いた `formatOrderLine` が前の定義を置き換えるため、引数一つ用の関数は選ばれません。  
必要なら、仮引数に **既定値** を書いておく方法があります。  
呼び出しで値が渡されなかったときだけ、その既定値が入ります。

```js
function formatOrderLine(name, quantity = 1) {
  return `${name} x${quantity}`;
}

console.log(formatOrderLine('mug')); // mug x1（quantity は既定値の 1）
console.log(formatOrderLine('mug', 2)); // mug x2
```

引数の個数や意味が大きく違う処理は、無理に同じ名前へ押し込めず、別の関数名に分ける方が追いやすいこともあります。

## 関数を値として渡す（コールバック）

JavaScript では、関数も **値** です。  
変数に入れたり、別の関数の引数として渡したりできます。

```js
function add(a, b) {
  return a + b;
}

const calculate = add;
console.log(calculate(2, 3)); // 5
```

`calculate` と `add` は、同じ関数を指しています。

引数として渡した関数は、呼び出し側の都合で **あとから実行** されます。  
この「渡された関数」のことを **コールバック関数** と呼びます。

```js
function applyDiscount(price, discountFn) {
  return discountFn(price);
}

function tenPercentOff(price) {
  return price * 0.9;
}

console.log(applyDiscount(1000, tenPercentOff)); // 900
```

`applyDiscount` は、渡された `discountFn` を中で呼び出しています。  
処理の共通部分（ここでは「割引を適用する」）と、変わる部分（割引率の計算）を分けられます。

アロー関数をその場で渡す書き方もよく使われます。

```js
console.log(applyDiscount(1000, (price) => price * 0.9)); // 900
```

### コールバックを呼び出す側を書く

コールバックは、**受け取った関数を必要なタイミングで呼ぶ側** から見ると理解しやすくなります。

```js
function repeat(count, action) {
  for (let i = 0; i < count; i++) {
    action(i);
  }
}

repeat(3, (index) => {
  console.log(`step ${index}`);
});
```

```text
step 0
step 1
step 2
```

`repeat` は `count` 回ループし、そのたびに渡された `action` を呼び出します。  
`action(i)` の `i` が、コールバック側の仮引数 `index` に渡されます。

このように、関数を引数へ渡すと、呼び出すタイミングと具体的な処理を分けられます。

:::tip[コールバックの読み方]

「この処理を、あとで実行してね」と関数を渡している、と捉えると追いやすくなります。

:::

## よくあるつまずき

- 関数を定義しただけで、呼び出していない
- `return` より後ろにも処理が続くと思う
- 戻り値が無い関数の結果を計算に使い、`undefined` になる
- 波括弧付きのアロー関数で `return` を書き忘れる
- 同じ名前の関数を引数違いで定義し、オーバーロードになると思う
- コールバックを渡しただけで、相手側が呼び出すのを忘れる

## まとめ / 次に学ぶとよいこと

- 関数は処理に名前を付け、`関数名(...)` で呼び出す仕組み
- 仮引数で値を受け取り、`return` で結果を返す
- `return` が無い関数の呼び出し結果は `undefined`
- 早期 `return` は処理できない条件を入口で終わらせる
- 短い処理では `const add = (a, b) => a + b` のようなアロー関数も使われる
- JavaScript は引数の違いによる関数のオーバーロードをしない
- 関数は値として変数へ入れ、別の関数の引数に渡せる
- コールバックは、受け取った側が必要なタイミングで呼び出す
