# 最初のプログラム

Web の記事から写した数行がブラウザでは動いたのに、同じコードをファイルに保存してターミナルから動かしたら、今度はエラーで止まった。  
JavaScript は動かせる場所がいくつもあるので、「どこで動かしているのか」が曖昧なままだと、こういう食い違いに足を取られます。  
そこで最初に、短いプログラムを自分の手で動かします。書いて、実行して、結果を見る。この一巡を通しておけば、この先のコードがどこで走っているのかを見失いません。

## このページで分かること

- Node.js を使えるか確認する方法
- JavaScript ファイルを作って実行する方法
- `console.log` と、プログラムが始まる場所

## なぜ最初に「動かす」か

この教材では、ブラウザの外で JavaScript を動かす **Node.js** を使います。  
Node.js は、JavaScript のコードを読み取って実行する仕組み（JavaScript エンジン）に、ファイル操作などの機能をまとめた実行環境です。  
ターミナルから `node ファイル名` と打つと、そのファイルの中身が実行されます。

実行する場所をここで Node.js に固定しておけば、以降のページのコードは、どれも同じ手順でそのまま動かせます。

## Node.js を確認する

まだインストールしていない場合は、[Node.js 公式サイト](https://nodejs.org/) から **LTS（長期サポート版）** の Node.js 20 以上をインストールします。  
インストール後はターミナルを開き直してから、次の確認へ進みます。

ターミナルで次のコマンドを実行します。

```bash
node -v
```

成功すると、インストールされているバージョンが表示されます。

```text
v20.18.0
```

先頭の `v20` がメジャーバージョンです。  
この教材では **Node.js 20 以上** を使います。

JavaScript は、実行の前に別のコンパイルコマンドを通す必要がありません。  
保存したファイルをそのまま `node` に渡せば動きます。

:::tip[確認する場所]

`node -v` で `v20` 以上が表示されれば、学習を始められます。

:::

## `order.js` を書く

作業用のディレクトリに、次の内容で `order.js` を保存します。

```js
console.log('order placed: mug');
```

`console.log(...)` は、丸括弧の中の値を画面へ一行出力します。  
文字列はシングルクォート `'...'` またはダブルクォート `"..."` で囲み、文の終わりにはセミコロン `;` を置きます。

JavaScript では、このファイル自体が実行の入口です。  
決まった名前のクラスや `main` 関数を用意しなくても、ファイルの先頭から順に処理されます。

## プログラムを実行する

ターミナルで `order.js` を保存したディレクトリへ移動し、次を実行します。

```bash
node order.js
```

成功すると、次の一行が表示されます。

```text
order placed: mug
```

コマンドは「`node` で `order.js` を実行する」と読みます。  
ファイル名の `.js` まで含めて指定するのがポイントです。

## ファイルは上から順に動く

出力を二行に増やすと、実行順を目で確認できます。

```js
console.log('start');
console.log('finish');
```

```text
start
finish
```

上の文が先に、下の文が後に実行されます。  
この素直な流れが基本で、条件分岐や繰り返しを使うと流れを変えられます。

<details>
<summary>ブラウザのコンソールとの違い</summary>

JavaScript は、Web ブラウザの開発者ツールにあるコンソールでも実行できます。  
ブラウザでは Web ページを操作する機能が使え、Node.js ではファイルやサーバーを扱うプログラムを実行できます。

この教材では、結果を同じ手順で確かめやすい Node.js を使います。  
`console.log` はどちらの環境でも利用できます。

</details>

<details>
<summary>node コマンドが見つからないとき</summary>

`node: command not found` や「'node' は認識されていません」と表示された場合は、Node.js が未インストールか、PATH が通っていない可能性があります。  
Node.js 20 以上を公式の手順でインストールし、ターミナルを開き直してから `node -v` をもう一度実行してください。

</details>

## よくあるつまずき

- `order.js.txt` のように、末尾へ `.txt` が付いたまま保存する
- `node order` と入力し、拡張子 `.js` を省略する
- 別のディレクトリでコマンドを実行し、ファイルが見つからない
- `"order placed: mug"` の閉じクォートや、`)` を書き忘れる

## まとめ / 次に学ぶとよいこと

- `node -v` で Node.js 20 以上が使えることを確認する
- JavaScript ファイルは `node ファイル名.js` で実行する
- ファイルが実行の入口になり、上から順に処理される
- `console.log(...)` で値を一行出力できる

次は [変数と計算](./variables-and-calculation) で、値に名前を付けて計算する方法を学びます。
