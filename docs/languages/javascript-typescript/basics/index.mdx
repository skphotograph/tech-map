# JavaScript 言語をはじめよう

この節では、入門編で基本構文とデータの扱い方を順に学び、小さなプログラムを自分で組み立てられるところまで土台を固めます。  
そのあとに **値と参照・実行の仕組み・非同期**、言語の骨格へ進みます。

:::info[読み方]

下のロードマップ **1〜8** が、変数・制御構文・関数などを学ぶ入門編です。  
経験にかかわらず先頭から順に進め、コード例を手元で動かし、理解チェックで確かめながら書き方を固めます。  
入門編を通して小さなプログラムを組み立てられるようになったら、9 以降へ進んでください。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- JavaScript を実行する仕組み（エンジン）で、同期の処理と「あとで動く」処理がどう並ぶか
- プリミティブとオブジェクト参照、等価比較、クラス、例外
- Promise / `async` / `await`、配列・オブジェクトの現代的な書き方

## 書き方だけ覚えても、あとでつまずく場面

入門書は文法中心になりがちですが、実務で最初に迷うのは「書けたけど、なぜこうなるのか」です。

- 関数に渡したオブジェクトの中身が、呼び出し元まで書き換わってしまう
- エラーが出たのに、どの行が原因か追えない
- 同じ値なのに `==` と `===` で結果が違う
- 非同期の処理が終わる前に、まだ途中の値を触ってしまう

こういう場面は、関数を呼んだあと値がどこに残るか、画面の更新やログ出力がどの順番で進むかといった **実行の仕組み** とセットで理解する必要があります。  
この節では書き方を覚えた直後にその地図を置き、あとから読む TypeScript や npm の話も「なぜそうするか」から追えるようにしています。

:::tip[この節のゴール]

小さなスクリプトを動かし、値と参照・非同期・例外の会話についていけ、現代的な構文を選ぶ理由を説明できる状態を目指します。

:::

## 学習のロードマップ

次の順で読むと、書き方を覚えたあと、そのコードがどの順番で動くかまで理解を積み上げられます。

**入門編：基本文法と書き方**

1. [最初のプログラム](./first-program) … Node.js、`console.log`、実行の最短ルート
2. [変数と計算](./variables-and-calculation) … `let` / `const`、型の感覚、四則演算、比較
3. [条件分岐](./branching) … `if` / `else`、三項演算子、`switch`、条件の組み合わせ
4. [繰り返し](./loops) … `for` / `while` / `for...of`、`break` / `continue`
5. [関数](./functions) … 定義と呼び出し、矢印関数、早期 `return`
6. [オブジェクト](./objects) … プロパティ、メソッド、分割代入の入口
7. [配列](./arrays) … 添字、更新、`map` / `filter` / `find` の入口
8. [モジュール](./modules) … `import` / `export`、ファイル分割

**実行と参照の地図**

9. [実行の仕組み](./execution-model) … エンジン、コールスタック、イベントループの入口
10. [型と参照](./types-and-references) … プリミティブとオブジェクト、コピーと共有
11. [等価と比較](./equality-and-coercion) … `===` / `==`、truthy / falsy

**言語の骨格**

12. [クラス](./classes) … `class`、コンストラクタ、継承の入口
13. [例外](./errors) … `try` / `catch`、`throw`、エラーの伝播
14. [Promise](./promises) … 非同期の約束、`then` / `catch`、合成
15. [`async` / `await` と fetch](./async-await-fetch) … 読みやすい非同期、HTTP の入口
16. [Map / Set](./map-set) … 一覧とキー付きデータの選び方
17. [現代的な構文](./modern-syntax) … 分割代入、スプレッド、`?.` / `??`

各ページでは、概念の区切りごとに **理解チェック**（選択式／穴埋め）を挟みます。  
「一つ読んで → 短く確認 → 次へ」のリズムです。これらの問題はテストではなく、その場で理解が正しいかを確認するためのものです。

各ページのコード例は、**ES2022 以降** と **Node.js 20 以降** を基準にしています。  
題材は架空の EC サイト（商品・注文・在庫）でそろえています。  
ブラウザでも同じ構文の多くは動きますが、実行手順の本線はターミナルの Node.js です。  
利用する環境のバージョンが異なる場合は、構文が使えるか公式ドキュメントで確認してください。

この節のあとは [TypeScript](../typescript/) へ進みます。
