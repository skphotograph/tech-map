# JavaScript / TypeScript をはじめよう

この章では、Web でもサーバでもよく使われる言語 **JavaScript** と、その上に型を足す **TypeScript** を学びます。  
ゴールは文法の暗記ではなく、レビュー、障害調査、フレームワーク学習で必要になる **実行の仕組み・値と参照・非同期・モジュール・型・依存管理** をつなげて理解することです。  
例は架空の EC サイト（商品・注文・在庫）でそろえ、現場でよく出るデータの形に寄せています。

## この章の進め方

共通基盤の Git や Linux と同じく、**書き方の入口から** 積み上げます。  
入門に必要な書き方は、**入門編で一通り網羅** します。入門編を通し終えてから、実行モデル・非同期・型の本編へ進みます。途中で飛ばさないのが基本です。

入門編で押さえること:

- 変数・計算、`if` / `for`、関数の定義と呼び出し
- オブジェクトと配列の読み書き
- 手元で Node.js から小さなプログラムを動かす
- `import` / `export` でファイルを分ける入口

本編で厚く扱うこと:

- プリミティブとオブジェクト参照の違い
- コールスタックとイベントループ（「あとで動く」の地図）
- Promise / `async` / `await`、例外
- TypeScript の型注釈と絞り込み
- npm による依存管理とスクリプト

:::info[読み方の目安]

はじめて近い人は、[JavaScript 言語](./basics/) の **入門編**（ロードマップ 1〜8）を順に通してから、[実行の仕組み](./basics/execution-model) 以降へ進んでください。  
すでに入門文法が手に馴染んでいる人は、入門編を流し読みしても構いませんが、実行・非同期のページに入る前に、自分の穴がないかだけ確認してください。

:::

## この章で分かること

- 小さな JavaScript プログラムを書いて動かす入口
- JavaScript がエンジン上でどう動き、非同期がどこに差し込まれるか
- 値と参照、等価比較、クラス、例外、現代的な構文の使いどころ
- TypeScript で型を付け、コンパイルして動かす流れ
- npm による依存管理とスクリプトの考え方
- Web アプリケーションの部品（HTTP クライアント、テストなど）の見方

## こんな場面で効く

「`undefined` がどこから来たのか追えない」  
「なぜ `==` ではなく `===` と言われるのか」  
「`await` を付け忘れて、まだ終わっていない値を触ってしまう」  
「フレームワークから呼ばれる関数や型定義が、何を受け取るのか想像できない」

土台が見えていると、ライブラリやフロント／バックの話が「魔法」ではなくなります。  
道具の使い方と、倉庫の地図がつながる、という感覚です。

:::tip[この章のゴール]

手元で JavaScript の基本を追い、実行と非同期のイメージを持ち、TypeScript と npm の感覚を持ったうえで、よく出る部品を中立的に説明できる状態を目指します。

:::

## 学習のロードマップ

1. [JavaScript 言語](./basics/) … 入門編、実行モデル、参照、等価、クラス、例外、非同期、現代構文
2. [TypeScript](./typescript/) … 型注釈、ユニオン、絞り込み、ジェネリクス、設定の入口
3. [npm と開発ツール](./tooling/) … `package.json`、依存、スクリプト、ロックファイル
4. [アプリケーション部品](./applications/) … HTTP クライアント、テスト、構成の見取り図

フレームワークは特定製品に寄せません。  
React も Vue も Express も Nest も、現場ではどれも出てきます。  
ここでは共通する考え方を先に持ち、各スタックの細部は公式ドキュメントや配属先の案内に任せます。

[共通基盤](../../foundations/)（Git / Linux など）を先に読んでおくと、コマンド例や調査の型が追いやすいです。  
すでに [Java](../java/) を読んでいる人は、「コンパイルと実行」「値と参照」の感覚を、この章の地図に載せ替えて読めます。
