# TypeScript をはじめよう

JavaScript で書いた処理が増えると、「この関数には何を渡せばよいか」「このオブジェクトにはどのプロパティがあるか」をコードだけで追うのが難しくなります。  
TypeScript は、その迷いを **型という約束** に変え、実行する前に食い違いを知らせてくれる言語です。

この節では、[JavaScript の基礎](../basics/) を土台に、型の付け方からコンパイル設定までを順に学びます。

## この節で分かること

- TypeScript が JavaScript のどんな困りごとを解決するか
- 基本の型と、型推論を活かした書き方
- オブジェクトの形、複数候補の型、安全な絞り込み
- ジェネリクスによる、型を保ったままの再利用
- `tsconfig.json` を使ったコンパイルと実行の流れ

## なぜ JavaScript のあとに学ぶのか

TypeScript の `if`、関数、配列、オブジェクトは、JavaScript と同じ考え方で動きます。  
そこへ型の情報を加え、入力ミスやデータの形の食い違いを、エディタやコンパイル時に見つけやすくします。

つまり、別の言語を一から覚え直すというより、JavaScript に **確認役を加える** イメージです。  
JavaScript の実行モデルを知っていると、「型は開発中に助け、実行時には JavaScript が動く」という役割分担も理解しやすくなります。

:::tip[この節のゴール]

小さな TypeScript プログラムに適切な型を付け、型エラーを読み、`tsconfig.json` の厳格な設定で JavaScript へコンパイルして実行できる状態を目指します。

:::

## 学習のロードマップ

次の順で進むと、「型を書く」から「型を使って安全に設計する」へ理解が積み上がります。

1. [TypeScript が必要な理由](./why-typescript) … 実行時エラーを早く見つけ、JavaScript へ変換する仕組み
2. [基本の型](./basic-types) … `string`、`number`、配列、型推論、`unknown`
3. [interface と type alias](./interfaces-and-aliases) … オブジェクトの形、任意プロパティ、読み取り専用
4. [ユニオン型と絞り込み](./unions-and-narrowing) … 複数の型を安全に扱う分岐
5. [ジェネリクス](./generics) … 型を保ったまま関数やデータ構造を再利用する方法
6. [tsconfig と開発の流れ](./tsconfig-and-workflow) … 厳格な型チェック、コンパイル、Node.js での実行

各ページでは、説明の区切りに **理解チェック** を挟みます。  
型エラーは失敗ではなく、実行前に見つかった修正の手がかりです。表示された型と、コードが実際に渡している値を見比べながら進めましょう。

この節のコード例は、**TypeScript 6.0 以降** と **Node.js 20 以降** を基準にしています。  
TypeScript の学習を終えたら、[npm と開発ツール](../tooling/) へ進み、パッケージ管理や開発コマンドを身につけます。
