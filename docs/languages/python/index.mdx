# Python をはじめよう

この章では、スクリプトからデータ処理、Web API、自動化まで幅広く使われる言語 **Python** を学びます。  
ゴールは文法の暗記ではなく、レビュー、障害調査、ライブラリ学習で必要になる **比較・クラス・例外・実行の仕組み・参照・型ヒント・仮想環境** をつなげて理解することです。  
出てくるコードは、商品の一覧を組み立てたり、注文を受けて在庫を減らしたりする小さな処理です。  
業務で扱うデータの形に近いので、読んだ書き方をそのまま仕事のコードに重ねられます。

## この章の進め方

共通基盤の Git や Linux と同じく、**書き方の入口から** 積み上げます。  
[Python 言語](./basics/) の **入門編**（ロードマップ 1〜16）で、教科書として必要な言語機能を一通り押さえてから、実行と参照の深掘り（17〜18）、型ヒント、依存管理へ進みます。途中で飛ばさないのが基本です。

入門編で押さえること:

- 変数・計算、文字列と `input`、`if` / `for`、関数の定義と呼び出し
- リスト・辞書の読み書き、文字列の分割と結合、`import` によるファイル分割
- `==` / `is`、`None`、truthy / falsy
- クラス、例外、内包表記、ファイル操作、現代的な構文の入口

入門編のあとに深掘りすること:

- インタプリタ、バイトコード、トレースバック、モジュール探索の仕組み
- 可変と不変、参照の共有、浅いコピー

:::info[読み方の目安]

はじめて近い人は、[Python 言語](./basics/) の **入門編**（ロードマップ 1〜16）を順に通してから、[実行の仕組み](./basics/execution-model) 以降へ進んでください。  
すでに入門文法が手に馴染んでいる人は、入門編を流し読みしても構いませんが、実行・参照のページに入る前に、自分の穴がないかだけ確認してください。

:::

## この章で分かること

- 小さな Python プログラムを書いて動かす入口
- 比較、クラス、例外、内包表記、ファイル操作
- インタプリタ上でコードがどう実行されるか
- 値と参照、比較、標準ライブラリの使いどころ
- 型ヒントを付け、ツールで確認する流れ
- venv / pip（または同等の道具）による依存管理の考え方
- HTTP クライアントやテストなど、アプリ寄りの部品の見方

## こんな場面で効く

「リストを渡したのに、呼び出し元まで中身が変わっている」  
「`if data:` が意図せず `False` になる」  
「同じ仮想環境だと思っていたら、別の Python を見ていた」  
「フレームワークの関数が、どの形の値を受け取って返すのか読み取れない」

土台が見えていると、ライブラリやフレームワークのコードでも、値がどこから来てどこへ渡るかを追いやすくなります。

:::tip[この章のゴール]

手元で Python の基本を追い、比較・クラス・例外を使い、実行と参照の地図を持ったうえで、型ヒントと仮想環境の感覚を持てる状態を目指します。

:::

## 学習のロードマップ

1. [Python 言語](./basics/) … 入門編（1〜16）、実行と参照（17〜18）
2. [型ヒント](./typing/) … 注釈、Optional / Union、ジェネリクスの入口、チェックツール

フレームワークは特定製品に寄せません。  
Django も FastAPI も Flask も、現場ではどれも出てきます。  
ここでは共通する考え方を先に持ち、各スタックの細部は公式ドキュメントや配属先の案内に任せます。

[共通基盤](../../foundations/)（Git / Linux など）を先に読んでおくと、コマンド例や調査の型が追いやすいです。  
すでに [Java](../java/) や [JavaScript / TypeScript](../javascript-typescript/) を読んでいる人は、「実行と参照」「依存管理」の感覚を、この章の地図に載せ替えて読めます。
