# 内包表記とイテラブル

一覧から必要な値を選び、加工して、別の一覧へ詰め直す。  
この処理はよく登場しますが、準備と追加処理が増えると「何を集めたいコードか」が見えにくくなります。  
Python の **内包表記**を使うと、一覧を作るための繰り返しをひとつの式にまとめられます。  

## このページで分かること

- リスト内包表記と `for` ループの対応
- 条件に合う要素だけをリストへ入れる方法
- 辞書内包表記の基本
- イテラブルが表す「値を順番に取り出せるもの」という共通性
- 内包表記と通常のループを選ぶ基準

## リスト内包表記で変換する

数値を二倍した新しいリストを、通常の `for` ループで作ります。  

```python
numbers = [1, 2, 3]
doubled = []

for number in numbers:
    doubled.append(number * 2)

print(doubled)
```

```text
[2, 4, 6]
```

この処理は、値を取り出し、変換し、新しいリストへ追加しています。  
同じ処理をリスト内包表記で書くと、次のようになります。  

```python
numbers = [1, 2, 3]
doubled = [number * 2 for number in numbers]

print(doubled)
```

```text
[2, 4, 6]
```

基本形は次のとおりです。  

```text
[ 作る値 for 要素 in 取り出し元 ]
```

`[number * 2 for number in numbers]` は、「`numbers` の各 `number` について、`number * 2` を集める」と読めます。  
この式は、次のループと同じ結果を作ります。  

```python
doubled = []

for number in numbers:
    doubled.append(number * 2)
```

内包表記は元のリストを変更せず、新しいリストを作ります。  

:::tip[通常のループへ戻して考える]

内包表記が分かりにくいときは、空のリスト、`for`、`append` の三段階へ書き戻すと処理を確認できます。  

:::

## `if` で集める要素を絞る

条件に合う要素だけを新しいリストへ入れるには、内包表記の末尾へ `if` を書きます。  

```python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)
```

```text
[2, 4, 6]
```

この内包表記は、次のループと同じ結果になります。  

```python
even_numbers = []

for number in numbers:
    if number % 2 == 0:
        even_numbers.append(number)
```

条件を通過した要素は、先頭に書いた式で変換できます。  

```python
prices = [500, 1200, 800, 2000]
tax_included = [price * 1.1 for price in prices if price >= 1000]

print(tax_included)
```

```text
[1320.0, 2200.0]
```

処理の順序は「取り出す → 条件で選ぶ → 選んだ値を変換して集める」です。  
コード上では、作る値を先頭に置き、条件を末尾に置きます。

## 条件で作る値を変える

すべての要素を残し、条件によって作る値を変えたい場合は、先頭の式に条件式を書きます。  

```python
scores = [45, 80, 60]
results = ["合格" if score >= 60 else "不合格" for score in scores]

print(results)
```

```text
['不合格', '合格', '合格']
```

二つの形は目的が異なります。  

```python
# 条件に合う要素だけを残す
passed_scores = [score for score in scores if score >= 60]

# 全要素を残し、条件によって値を変える
labels = ["合格" if score >= 60 else "不合格" for score in scores]
```

- 末尾の `if` は、要素を入れるか除外するかを決める
- 先頭の `if ... else ...` は、入れる値を二通りから選ぶ

条件が増えて読みにくくなる場合は、通常の `for` ループか関数へ分けます。  

## 辞書内包表記でキーと値を作る

辞書を作る内包表記では、波括弧の中へ `キー: 値` と `for` を書きます。  

```python
users = ["Aiko", "Ren", "Mika"]
name_lengths = {user: len(user) for user in users}

print(name_lengths)
```

```text
{'Aiko': 4, 'Ren': 3, 'Mika': 4}
```

`user` をキー、`len(user)` を値にした辞書を作っています。  
通常のループでは、次のように書けます。  

```python
name_lengths = {}

for user in users:
    name_lengths[user] = len(user)
```

既存の辞書から、条件に合う項目だけを集めることもできます。  

```python
stocks = {"book": 3, "pen": 0, "notebook": 5}
available = {name: stock for name, stock in stocks.items() if stock > 0}

print(available)
```

```text
{'book': 3, 'notebook': 5}
```

`stocks.items()` からキーと値の組を取り出し、在庫がある項目だけで新しい辞書を作っています。

## イテラブルは値を順番に取り出せるもの

`for` の `in` の右側には、リスト以外も置けます。  
`for` で値をひとつずつ取り出せるオブジェクトを **イテラブル** と呼びます。  

よく使うイテラブルには、次のものがあります。  

- リスト
- タプル
- 文字列
- 辞書
- 集合
- `range`
- 開いているファイル

文字列からは、一文字ずつ取り出せます。  

```python
characters = [character for character in "API"]
print(characters)
```

```text
['A', 'P', 'I']
```

`range` も整数を順番に提供するイテラブルです。  

```python
squares = [number ** 2 for number in range(4)]
print(squares)
```

```text
[0, 1, 4, 9]
```

辞書をそのまま反復すると、キーが取り出されます。  

```python
stocks = {"book": 3, "pen": 1}

for name in stocks:
    print(name)
```

```text
book
pen
```

キーと値の両方が必要なら `items()` を使います。  

```python
for name, stock in stocks.items():
    print(f"{name}: {stock}")
```

イテラブルという共通点があるため、同じ `for` や内包表記で異なる種類の値を処理できます。  
一方、取り出す順序や内容は型によって異なるため、各型の規則も確認します。

## 内包表記を使うか判断する

内包表記は、「値を取り出し、短い式で変換または選別して、新しいコレクションを作る」処理に向いています。  

```python
active_names = [user["name"] for user in users if user["active"]]
```

複数の分岐、ログ出力、状態の更新が入るなら、内包表記へ詰め込みません。  
通常のループへ分けた方が、どの条件で何が実行されるかを上から追いやすくなります。  

```python
active_names = []

for user in users:
    if not user["active"]:
        print(f'{user["name"]} は対象外です')
        continue

    active_names.append(user["name"])
```

:::tip[読みやすさを基準にする]

変換や絞り込みが一目で分かるなら内包表記、途中経過を順に追う必要があるなら通常の `for` を選びます。  

:::

<details>
<summary>ジェネレータ式で値を必要な分だけ作る</summary>

リスト内包表記の角括弧を丸括弧に変えると、**ジェネレータ式**になります。  

```python
squares = (number ** 2 for number in range(1_000_000))
```

ジェネレータ式は、すべての結果を最初にリストへ保存せず、反復するときに値をひとつずつ作ります。  
大量の値を一度だけ順番に処理する場合、メモリ使用量を抑えられます。  

```python
total = sum(number ** 2 for number in range(4))
print(total)  # 14
```

一度取り出した値を同じジェネレータから再び取り出すことはできません。  
結果を何度も使う、添字で読む、要素を追加するといった用途にはリストを選びます。  

</details>

## よくあるつまずき

- 内包表記の先頭に、作りたい値ではなく取り出し元を書く
- 末尾の `if` と、先頭の `if ... else ...` の目的を取り違える
- 元のリストも内包表記によって変更されると思う
- 辞書を反復すると値ではなくキーが取り出されることを見落とす
- 分岐や副作用を一行へ詰め込み、処理の順番を追いにくくする

## まとめ / 次に学ぶとよいこと

- リスト内包表記は、変換して `append` する `for` ループをひとつの式で表す
- 末尾の `if` で、集める要素を絞り込める
- 辞書内包表記は `{キー: 値 for 要素 in イテラブル}` と書く
- イテラブルは、`for` で値をひとつずつ取り出せるオブジェクト
- 処理が複雑になる場合は、通常の `for` ループへ分ける
