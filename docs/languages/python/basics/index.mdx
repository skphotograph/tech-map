# Python 言語をはじめよう

この節では、入門編で基本構文とデータの扱い方を順に学び、小さなプログラムを自分で組み立てられるところまで土台を固めます。  
そのあとに **値と参照・実行の仕組み・例外**、言語の骨格へ進みます。

:::info[読み方]

下のロードマップ **1〜8** が、変数・制御構文・関数などを学ぶ入門編です。  
経験にかかわらず先頭から順に進め、コード例を手元で動かし、理解チェックで確かめながら書き方を固めます。  
入門編を通して小さなプログラムを組み立てられるようになったら、9 以降へ進んでください。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- インタプリタがソースをどう実行するか
- 可変と不変、参照の共有、等価比較、クラス、例外
- 内包表記、ファイル操作、現代的な構文の使いどころ

## 書き方だけ覚えても、あとでつまずく場面

入門書は文法中心になりがちですが、実務で最初に迷うのは「書けたけど、なぜこうなるのか」です。

- 関数に渡したリストの中身が、呼び出し元まで書き換わってしまう
- エラーが出たのに、どの行が原因か追えない
- `if items:` が空リストで意図せずスキップされる
- 同じ文字列なのに `is` と `==` で結果が違う

こういう場面は、`import` で読み込むファイルの探し方、エラーが呼び出し元までどう伝わるかといった **実行の仕組み** とセットで理解する必要があります。  
この節では書き方を覚えた直後にその地図を置き、あとから読む型ヒントやパッケージ管理の話も「なぜそうするか」から追えるようにしています。

:::tip[この節のゴール]

小さなスクリプトを動かし、値と参照・例外の会話についていけ、標準的な書き方を選ぶ理由を説明できる状態を目指します。

:::

## 学習のロードマップ

次の順で読むと、理解が積み上がりやすいです。

**入門編：基本文法と書き方**

1. [最初のプログラム](./first-program) … `python`、`print`、実行の最短ルート
2. [変数と計算](./variables-and-calculation) … 代入、型の感覚、四則演算、比較
3. [条件分岐](./branching) … `if` / `elif` / `else`、条件の組み合わせ
4. [繰り返し](./loops) … `for` / `while`、`range`、`break` / `continue`
5. [関数](./functions) … 定義と呼び出し、既定引数、早期 `return`
6. [リストとタプル](./lists-and-tuples) … 順番付きの一覧、可変と不変
7. [辞書と集合](./dicts-and-sets) … キーと値、重複なしの集まり
8. [モジュール](./modules) … `import`、パッケージ、ファイル分割

**実行と参照の地図**

9. [実行の仕組み](./execution-model) … インタプリタ、バイトコード、モジュール探索の入口
10. [型と参照](./types-and-references) … 可変と不変、コピーと共有
11. [等価と比較](./equality-and-truthiness) … `==` / `is`、truthy / falsy、`None`

**言語の骨格**

12. [クラス](./classes) … `class`、`__init__`、メソッド、継承の入口
13. [例外](./exceptions) … `try` / `except`、`raise`、例外の伝播
14. [内包表記とイテラブル](./comprehensions-and-iterables) … 一覧の変換、`for` との対応
15. [ファイルと pathlib](./files-and-pathlib) … 読み書き、パス操作
16. [現代的な構文](./modern-syntax) … アンパック、`match` の入口、便利な書き方

各ページでは、概念の区切りごとに **理解チェック**（選択式／穴埋め）を挟みます。  
「一つ読んで → 短く確認 → 次へ」のリズムです。これらの問題はテストではなく、その場で理解が正しいかを確認するためのものです。

各ページのコード例は、**Python 3.11 以降** を基準にしています。  
題材は架空の EC サイト（商品・注文・在庫）でそろえています。  
利用する環境のバージョンが異なる場合は、構文が使えるか公式ドキュメントで確認してください。
