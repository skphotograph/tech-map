# Python 言語をはじめよう

この節では、まず **入門編** で書き方とよく使う言語機能を一通り押さえ、**実行の仕組みと参照** を深掘りしてから、型ヒントへ進みます。

:::info[読み方]

入門編は、変数・制御構文・関数・クラス・例外・ファイル操作まで **入門教科書として必要な範囲を一通り網羅** します。  
たとえ話多めで噛み砕いているので、手が動く人は流し読みで構いません。不安なところだけ戻っても大丈夫です。  
はじめて近い人は、下のロードマップ **1〜16**（入門編）を順に通してください。  
17 以降は、入門編を通し終えてからで構いません。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- 比較・クラス・例外・内包表記・ファイル操作・現代的な構文
- インタプリタがソースをどう実行するか
- 可変と不変、参照の共有、コピーと共有

## なぜ入門のあとに実行と参照を深掘りするか

現場で最初につまずきやすいのは、構文そのものより次のような場面です。

- 値が設定されていない `None` のまま処理し、どこでそうなったか追えない
- 渡したリストの中身が、呼び出し元まで書き換わる
- `if items:` が空リストで意図せずスキップされる
- 実行環境の違いで、「手元では動くのに CI ではモジュールが見つからない」

入門編では `==` / `is` や例外の **使い方** を先に押さえます。  
そのうえで、トレースバックの読み方や参照の共有といった **仕組み** を 17〜18 でまとめて整理します。  
ここで一度つなげておくと、あとから読む型ヒントやパッケージ管理が「設定の暗記」になりにくいです。

:::tip[この節のゴール]

小さなスクリプトを書き、比較・クラス・例外の会話についていけ、実行と参照の地図も持てる状態を目指します。

:::

## 学習のロードマップ

5. [繰り返し](./loops) … `for` / `while`、`enumerate` / `zip` / `sorted`
6. [関数](./functions) … 定義と呼び出し、スコープ、docstring、既定引数

各ページでは、概念の区切りごとに **理解チェック**（選択式／穴埋め）を挟みます。  
「一つ読んで → 短く確認 → 次へ」のリズムです。これらの問題はテストではなく、その場で理解が正しいかを確認するためのものです。

各ページのコード例は、**Python 3.11 以降** を基準にしています。  
題材は架空の EC サイト（商品・注文・在庫）でそろえています。  
利用する環境のバージョンが異なる場合は、構文が使えるか公式ドキュメントで確認してください。
