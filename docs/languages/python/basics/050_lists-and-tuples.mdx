# リストとタプル

処理する注文が増えるたびに `order1`、`order2` と変数を増やすと、一覧を数えるだけでも手間がかかります。  
Python では、複数の値を順番付きで扱うために **リスト** と **タプル** を使います。  
見た目は似ていますが、あとから中身を変更できるかどうかが大きな違いです。

## このページで分かること

- リストを作り、添字で要素を読む
- `append` / `pop` でリストを更新する
- `len` と `for` で一覧を扱う
- スライスで一部分を取り出す
- リストとタプルを目的に合わせて選ぶ

## リストは変更できる順番付きの一覧

リストは、複数の値を順番に並べたものです。  
角括弧 `[]` の中に、要素をカンマで区切って書きます。

```python
statuses = ["受付", "処理中", "完了"]
```

要素の位置を表す番号を **添字（インデックス）** と呼びます。  
Python の添字は `0` から始まります。

```python
print(statuses[0])  # 受付
print(statuses[1])  # 処理中
```

要素数は `len` 関数で調べられます。

```python
print(len(statuses))  # 3
```

有効な添字は `0` から `len(statuses) - 1` までです。  
範囲外の添字を読むと `IndexError` になります。

:::tip[添字は 0 から]

先頭は `list[0]`、最後は `list[len(list) - 1]` です。

:::

## `append` と `pop` で末尾を更新する

リストは、作ったあとから中身を変更できます。  
この性質を **可変（ミュータブル）** と呼びます。

末尾へ要素を追加するには `append` を使います。

```python
order_ids = ["ORD-1001", "ORD-1002"]
order_ids.append("ORD-1003")

print(order_ids)
```

実行結果です。

```text
['ORD-1001', 'ORD-1002', 'ORD-1003']
```

末尾の要素を取り出して削除するには `pop` を使います。

```python
last_id = order_ids.pop()

print(last_id)   # ORD-1003
print(order_ids) # ['ORD-1001', 'ORD-1002']
```

`append` はリストそのものを更新し、戻り値は `None` です。  
`pop` はリストを更新すると同時に、削除した要素を返します。

## `for` で要素を順番に読む

全要素を先頭から処理するなら、`for` でリストから要素をひとつずつ受け取ります。

```python
order_ids = ["ORD-1001", "ORD-1002", "ORD-1003"]

for order_id in order_ids:
    print(order_id)
```

実行結果です。

```text
ORD-1001
ORD-1002
ORD-1003
```

`order_id` には、繰り返すたびに次の要素が入ります。  
要素そのものが欲しい場面では、添字を使って取り出すより意図が伝わりやすい書き方です。

## スライスで一部分を取り出す

リストの連続した一部分が必要なときは、**スライス**を使います。  
`list[開始:終了]` と書き、開始位置の要素を含み、終了位置の要素は含みません。

```python
quantities = [2, 1, 3, 2]

print(quantities[1:3])  # [1, 3]
```

`quantities[1:3]` は、添字 `1` から添字 `3` の手前までを取り出します。  
元のリストは変更されず、取り出した要素を持つ新しいリストが作られます。

```python
print(quantities)  # [2, 1, 3, 2]
```

開始を省略すると先頭から、終了を省略すると末尾までになります。

```python
print(quantities[:2])  # [2, 1]
print(quantities[2:])  # [3, 2]
```

## タプルは変更できない順番付きの組

タプルも、複数の値を順番付きで持ちます。  
丸括弧 `()` の中に要素を書きます。

```python
line_item = ("mug", 2)

print(line_item[0])   # mug
print(len(line_item)) # 2
```

タプルは作成後に要素を追加・削除・置換できません。  
この性質を **不変（イミュータブル）** と呼びます。

```python
line_item[0] = "cable"  # TypeError
```

商品コードと数量のような固定の組や、処理の途中で変わってほしくない値に向いています。  
不変な要素だけを持つタプルは、辞書のキーとして使える場合もあります。

要素を増減・置換する一覧にはリスト、固定された値の組にはタプルを使います。

:::

## よくあるつまずき

- 先頭の添字を `1` だと思い、ひとつ後ろの要素を読む
- `append` の戻り値を更新後のリストだと思って変数へ代入する
- `pop` が元のリストも変更することを見落とす
- スライスの終了位置の要素も含まれると思う
- 変更が必要な一覧をタプルで作り、あとから要素を追加しようとする

## まとめ / 次に学ぶとよいこと

- リストは変更できる順番付きの一覧で、添字は `0` から始まる
- `append` は末尾へ追加し、`pop` は末尾から取り出して削除する
- `len` は要素数を返し、`for item in list` で各要素を読める
- `list[1:3]` は添字 `1` から `3` の手前までを取り出す
- タプルは変更できない順番付きの組で、固定した値に向く
