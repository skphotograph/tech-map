# モジュール

便利な計算を見つけても、必要なファイルへ毎回コピーしていると、修正箇所が増えていきます。  
片方だけ直し忘れれば、呼び出す場所によって結果が変わります。  
Python の **モジュール**を使うと、関数や値をファイルに分け、必要な場所から再利用できます。

## このページで分かること

- 役割ごとにファイルを分ける理由
- `import order_totals` でモジュールを読み込む
- `from order_totals import add` で名前を直接読み込む
- `if __name__ == "__main__":` で直接実行時だけ処理する
- `__init__.py` を持つパッケージの基本

## ファイルを役割で分ける

プログラムが育つと、計算、表示、データの読み込みなど、異なる役割のコードがひとつのファイルに集まります。  
長いファイルを短く切ること自体が目的ではありません。  
何を担当するコードかが分かる単位に分けると、変更する場所と再利用する場所を見つけやすくなります。

Python では、ひとつの `.py` ファイルを **モジュール**として読み込めます。  
ここでは、注文金額の合計を担当する `order_totals.py` と、それを使う `main.py` に分けます。

```text
module-sample/
├── order_totals.py
└── main.py
```

`order_totals.py` に関数を定義します。

```python title="order_totals.py"
def add(left, right):
    return left + right


def multiply(left, right):
    return left * right
```

## `import order_totals` でモジュールを読み込む

同じディレクトリの `main.py` から `order_totals.py` を読み込みます。

```python title="main.py"
import order_totals

total = order_totals.add(1200, 800)
print(total)
```

ターミナルで `main.py` を実行します。

```bash
python main.py
```

実行結果です。

```text
2000
```

`import order_totals` によって、`order_totals.py` が `order_totals` という名前で使えるようになります。  
関数は `order_totals.add` のように、モジュール名を付けて呼び出します。

:::tip[モジュール名を残す利点]

`order_totals.add` と書くと、`add` が `order_totals` モジュールから来た関数だとコード上で分かります。

:::

## `from` で必要な名前を読み込む

モジュールから特定の名前だけを読み込むには、`from ... import ...` を使います。

```python title="main.py"
from order_totals import add

total = add(1200, 800)
print(total)
```

この場合は、モジュール名を付けずに `add` と呼び出せます。  
短く書けますが、同じ名前の関数を別の場所で定義すると、どの `add` か見分けにくくなります。

- 出どころを明確にしたいなら `import order_totals` と `order_totals.add`
- 使う名前が少なく、衝突しないなら `from order_totals import add`

`from order_totals import *` は、どの名前を読み込んだか分かりにくくなるため避けます。

## インポートするとファイルの処理が実行される

Python はモジュールを初めてインポートするとき、そのファイルのトップレベルに書かれた処理を上から実行します。  
関数定義だけでなく、直接書いた `print` も実行対象です。

```python title="order_totals.py"
print("order_totals を読み込みました")


def add(left, right):
    return left + right
```

```python title="main.py"
import order_totals

print(order_totals.add(2, 3))
```

実行結果です。

```text
order_totals を読み込みました
5
```

動作確認用のコードをトップレベルへ置くと、再利用のためにインポートしただけでも実行されます。  
そこで、直接実行したときだけ動かす処理を条件で分けます。

## `if __name__ == "__main__":` で実行を分ける

Python は、各モジュールに `__name__` という特別な変数を用意します。

- ファイルを直接実行したときは `__name__` が `"__main__"` になる
- 別ファイルからインポートしたときは `__name__` がモジュール名になる

この違いを使うと、動作確認やプログラムの開始処理を直接実行時だけ動かせます。

```python title="order_totals.py"
def add(left, right):
    return left + right


if __name__ == "__main__":
    print(add(2, 3))
```

`python order_totals.py` と直接実行すると `5` が表示されます。  
一方、`main.py` から `import order_totals` しても、条件の中の `print` は実行されません。

:::tip[`__main__` の目的]

再利用する定義と、直接実行したときだけ行う開始処理を同じファイル内で分けるために使います。

:::

## パッケージで複数のモジュールをまとめる

関連するモジュールが増えたら、ディレクトリにまとめて **パッケージ**として扱えます。  
この教材では、パッケージであることを明示する `__init__.py` を置く一般的な構成を使います。

```text
module-sample/
├── main.py
└── shop/
    ├── __init__.py
    └── order_totals.py
```

`shop/order_totals.py` の関数は、次のように読み込めます。

```python title="main.py"
from shop.order_totals import add

print(add(1200, 800))
```

`__init__.py` は空でも構いません。  
Python 3 には `__init__.py` がない名前空間パッケージもありますが、まずはパッケージの境界が見えるこの構成を基本にします。

<details>
<summary>Python がモジュールを探す場所</summary>

`import` が実行されると、Python は組み込みモジュールや、実行時の検索先に並んだディレクトリから対象を探します。  
検索先は `sys.path` で確認できます。

```python
import sys

for path in sys.path:
    print(path)
```

実行したスクリプトの場所、標準ライブラリ、利用中の環境へインストールされたパッケージの場所などが含まれます。  
検索先を場当たり的に書き換えるより、正しいディレクトリから実行し、必要なパッケージを利用中の環境へインストールすることが大切です。

</details>

## よくあるつまずき

- `order_totals.py` と `main.py` の配置や実行するディレクトリが想定と異なる
- `import order_totals` のあと、`order_totals.add` ではなく `add` と直接呼ぶ
- 動作確認の `print` をトップレベルへ置き、インポート時にも実行させる
- ファイル名を `json.py` など標準ライブラリと同じ名前にし、意図しない方を読み込む
- `from module import *` を使い、名前の出どころを追えなくする

## まとめ / 次に学ぶとよいこと

- `.py` ファイルはモジュールとして読み込める
- `import order_totals` では `order_totals.add`、`from order_totals import add` では `add` と呼ぶ
- インポート時には、モジュールのトップレベルの処理が実行される
- `if __name__ == "__main__":` は直接実行時だけ開始処理を動かす
- 関連するモジュールは、`__init__.py` を持つパッケージにまとめられる
