# 辞書と集合

注文番号、状態、金額を別々のリストに入れると、同じ位置の値が同じ注文を表す、という約束が必要になります。  
ひとつずれるだけで、注文番号と金額の対応が崩れます。  
Python の **辞書**は値へ名前を付け、**集合**は重複のない値をまとめるためのデータ構造です。  

## このページで分かること

- 辞書でキーと値の対応を表す
- `[]` と `get` で値を取得する
- `keys` / `values` / `items` を繰り返す
- 集合で重複を除き、要素を追加・確認する
- リスト・辞書・集合を目的に合わせて選ぶ

## 辞書はキーと値の対応を持つ

辞書は、**キー**と**値**を組み合わせて保存します。  
波括弧 `{}` の中に `キー: 値` をカンマで区切って書きます。  

```python
order = {
    "id": "ORD-1001",
    "status": "受付",
    "total": 1500,
}
```

キーを角括弧に指定すると、対応する値を取得できます。  

```python
print(order["id"])      # ORD-1001
print(order["status"])  # 受付
```

値の追加と更新にも同じ書き方を使います。  

```python
order["customer"] = "Aiko"
order["status"] = "完了"

print(order["status"])  # 完了
```

辞書はリストと同じく可変です。  
代入によって、辞書そのものの内容が変わります。  

:::tip[辞書が表すもの]

辞書は「キーから値を引く対応表」です。位置ではなく名前で値を読みたいときに使います。  

:::

## `[]` と `get` を使い分ける

存在しないキーを `[]` で読むと `KeyError` になります。  
必ず存在するはずのキーなら、データの不足にすぐ気づけるこの動作が役立ちます。  

```python
order = {"id": "ORD-1001"}
print(order["status"])  # KeyError
```

キーがなくても処理を続けたい場合は `get` を使います。  
存在しないキーに対して、既定では `None` を返します。  

```python
print(order.get("status"))  # None
```

第 2 引数で、キーがない場合の値を指定できます。  

```python
print(order.get("status", "未設定"))  # 未設定
```

「必須項目なので、なければ不具合として扱う」なら `[]`、「省略できる項目なので代わりの値を使う」なら `get`、という目的で選びます。  

## キー・値・組を繰り返す

辞書が持つキーは `keys`、値は `values`、キーと値の組は `items` で取得できます。  

```python
order = {
    "id": "ORD-1001",
    "status": "受付",
    "total": 1500,
}

for key in order.keys():
    print(key)
```

実行結果です。  

```text
id
status
total
```

値だけが必要なら `values` を使います。  

```python
for value in order.values():
    print(value)
```

キーと値の両方が必要なら `items` を使います。  

```python
for key, value in order.items():
    print(f"{key}: {value}")
```

実行結果です。  

```text
id: ORD-1001
status: 受付
total: 1500
```

`for key, value` では、`items` が返すキーと値の組を 2 つの変数で受け取っています。

## 集合は重複のない集まり

集合は、重複しない要素を持つデータ構造です。  
順番や位置ではなく、「その値が含まれているか」を扱う場面に向いています。  

```python
tags = {"python", "backend", "python"}

print(tags)
```

`"python"` を 2 回書いても、集合にはひとつだけ保持されます。  
集合の表示順には依存しないでください。  

要素の追加には `add` を使います。  

```python
tags.add("api")
```

要素が含まれているかは `in` で確認できます。  

```python
print("python" in tags)  # True
print("java" in tags)    # False
```

空の集合は `{}` ではなく `set()` で作ります。  
`{}` は空の辞書を表すためです。  

```python
tags = set()
tags.add("python")
```

## リスト・辞書・集合を目的で選ぶ

3 つのデータ構造は、保存した値をどう使うかで選びます。  

- 順番に並べ、同じ値の重複も保持するならリスト
- 名前や ID から対応する値を取り出すなら辞書
- 重複を除き、含まれているか調べるなら集合

たとえば、処理順を保つ注文一覧はリスト、注文番号から注文情報を引く対応表は辞書、処理済みの注文番号を重複なく記録するなら集合が候補になります。  

:::tip[形ではなく目的で選ぶ]

順番ならリスト、キーから値を引くなら辞書、重複なしの所属確認なら集合です。  

:::

## よくあるつまずき

- 存在しない必須キーを `get` で読み、データ不足を見逃す
- 省略できるキーを `[]` で読み、`KeyError` にする
- `keys`、`values`、`items` の括弧 `()` を付け忘れる
- 集合の表示順や添字に依存する
- 空の集合を `{}` で作ろうとして、空の辞書を作る

## まとめ / 次に学ぶとよいこと

- 辞書はキーと値の対応を持ち、`dict[key]` で値を読む
- `get` はキーがない場合に `None` または指定した既定値を返す
- `keys` / `values` / `items` で、必要な部分を繰り返せる
- 集合は重複のない値を持ち、`add` で追加し、`in` で所属を確認する
- リスト・辞書・集合は、順番・対応・重複なしという目的で選ぶ
