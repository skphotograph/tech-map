# ファイルと pathlib

ログや設定を書き出したあと、実行する場所が変わるとファイルが見つからない。  
文字化けしてから、文字コードを指定していなかったことに気づく。  
ファイル操作では、内容だけでなく「どのパスを、どの文字コードで開くか」までコードに表すことが大切です。

## このページで分かること

- `with open(...)` でテキストを安全に読み書きする方法
- `pathlib.Path` でパスを組み立てる方法
- `read_text` / `write_text` の使いどころ
- ファイルが存在しない場合の扱い

## `with` でファイルを開く

`open` はファイルを開き、ファイルオブジェクトを返します。  
`with` と組み合わせると、処理が終わったときや例外が起きたときにも自動で閉じられます。

```python
with open("orders.csv", mode="r", encoding="utf-8") as f:
    text = f.read()

print(text)
```

`orders.csv` に `ORD-1001,OPEN` と書かれていれば、実行結果は次のとおりです。

```text
ORD-1001,OPEN
```

`mode="r"` は読み込みです。  
書き込みには `"w"`、末尾への追記には `"a"` を使います。

`encoding="utf-8"` は、文字をファイル内のバイトへ変換する規則を指定します。  
書き込み時と読み込み時で同じ文字コードを使うことで、日本語などが文字化けする問題を避けやすくなります。

```python
with open("order_status.log", mode="w", encoding="utf-8") as f:
    f.write("ORD-1001 を受付しました\n")
```

`"w"` は既存の内容を上書きします。  
残したいファイルへ誤って使わないよう、対象のパスとモードを一緒に確認してください。

:::tip[文字コードを明示する]

テキストファイルでは `encoding="utf-8"` を明示すると、端末や OS が変わっても意図した文字コードで扱いやすくなります。

:::

## `Path` でパスを扱う

文字列を `/` や `\` でつなぐと、OS ごとの差や区切りの重複が入り込みます。  
`pathlib` の `Path` は、パスを値として組み立て、調べ、操作する標準ライブラリです。

```python
from pathlib import Path

data_dir = Path("data")
file_path = data_dir / "orders.csv"

print(file_path)
print(file_path.name)
```

実行結果の例です。

```text
data/orders.csv
orders.csv
```

表示される区切り文字は OS によって異なります。  
`/` 演算子は文字列の割り算ではなく、`Path` に子のパスをつなぐ書き方です。

よく使う確認方法は次のとおりです。

```python
from pathlib import Path

path = Path("data/orders.csv")

print(path.exists())
print(path.is_file())
print(path.parent)
```

- `exists()` はパスが存在するかを返す
- `is_file()` は通常のファイルかを返す
- `parent` は親ディレクトリを表す
- `name` は末尾のファイル名を表す

## 短い読み書きには `read_text` と `write_text`

ファイル全体を一度に扱うなら、`Path` のメソッドで簡潔に書けます。

```python
from pathlib import Path

path = Path("order_status.log")
path.write_text("ORD-1001: OPEN\n", encoding="utf-8")

text = path.read_text(encoding="utf-8")
print(text, end="")
```

実行結果です。

```text
ORD-1001: OPEN
```

`write_text` は既存の内容を置き換え、書き込んだ文字数を返します。  
大きなログを一行ずつ処理したい場合は、ファイル全体をメモリへ読む `read_text` より、`with open(...)` で反復する方が向いています。

```python
from pathlib import Path

path = Path("order_status.log")

with path.open(mode="r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())
```

## よくあるつまずき

相対パスは、ソースファイルの場所ではなく、通常はコマンドを実行した **カレントディレクトリ** を基準に解決されます。  
見つからないときは `Path.cwd()` で現在地を確認します。

```python
from pathlib import Path

print(Path.cwd())
```

存在しないファイルを読むと `FileNotFoundError` が発生します。  
存在しないことが通常の分岐なら `exists()` で確認し、存在すべきファイルなら例外を握りつぶさず、パスの誤りとして調査します。

## まとめ

- `with open(...)` はファイルを確実に閉じる
- テキストでは `encoding="utf-8"` を明示する
- `Path` は OS の違いを意識しすぎずにパスを組み立てられる
- 小さなファイル全体には `read_text` / `write_text`、逐次処理には `open` を使う
