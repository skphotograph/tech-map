# 変数と計算

注文金額の `1200` がコードのあちこちに現れると、それが単価なのか合計なのか分からなくなります。  
値に意味の分かる名前を付ければ、計算の意図をコードに残せます。

ここでは、Python で値へ名前を付け、文字列に埋め込み、計算して比べるところまで進めます。

## このページで分かること

- `=` で値を名前へ代入する方法
- `int`、`float`、`str`、`bool`、`None` の役割
- f-string で文字列へ値を埋め込む方法
- 算術演算、比較、値の更新の書き方

## 名前を値へ結び付ける

Python では、`=` を使って値に名前を付けます。

```python
unit_price = 350
quantity = 2
```

`=` は「等しい」ではなく、右側の値を左側の名前へ結び付ける **代入** です。  
上のコードでは、`unit_price` が `350`、`quantity` が `2` を指します。

変数を箱として考える説明もありますが、Python では「名前というラベルを値へ貼る」と捉えると、同じ値に複数の名前を付けた場合の動きも理解しやすくなります。

```python
quantity = 2
quantity = 3

print(quantity)
```

```text
3
```

二回目の代入によって、`quantity` は新しい値 `3` を指すようになります。  
Python には JavaScript の `let` や `const` に当たる変数宣言がなく、名前は別の値へ再代入できます。

:::tip[等しいと代入を分ける]

`=` は代入です。  
二つの値が等しいかを調べるときは `==` を使います。

:::

<details>
<summary>定数を表す名前の慣習</summary>

Python の名前は、仕組み上はどれも再代入できます。  
プログラム中で変更しない値は、`TAX_RATE` のような大文字とアンダースコアの名前にして、定数として扱う意思を示す慣習があります。

```python
TAX_RATE = 0.1
```

この書き方でも再代入は禁止されません。  
「変更しない」という読み手との約束なので、名前だけでなくコードレビューや検査ツールも組み合わせて守ります。

</details>

## 値には型がある

Python では、変数を作るときに型名を書きません。  
一方で、実行時の値には型があり、できる操作は型によって変わります。

| 型      | 意味                       | 例                  |
| ------- | -------------------------- | ------------------- |
| `int`   | 整数                       | `10`, `-1`, `0`     |
| `float` | 小数                       | `3.5`, `0.1`        |
| `str`   | 文字列                     | `"order"`, `'PAID'` |
| `bool`  | 真偽                       | `True`, `False`     |
| `None`  | 値がないことを示す特別な値 | `None`              |

```python
amount = 1200
tax_rate = 0.1
status = "PAID"
available = True
assignee = None

print(type(amount))
print(type(status))
```

```text
<class 'int'>
<class 'str'>
```

`type(...)` は値の型を返します。  
出力の `int` と `str` を見れば、それぞれ整数と文字列であることを確認できます。

Python の真偽値は、先頭を大文字にした `True` と `False` です。  
`None` は、たとえば「担当者という項目はあるが、現在は担当者がいない」という状態を表せます。

名前には別の型の値も再代入できます。

```python
order_id = 1001
order_id = "order-1001"
```

Python は実行時に型を扱うため、この再代入自体は可能です。  
ただし、同じ名前の型が途中で変わると読み手が追いにくくなるため、通常は一つの役割に一貫した型を使います。

## f-string で値を文字列へ埋め込む

変数の値を含むメッセージを作るときは、**f-string** が読みやすい書き方です。  
文字列の開始クォートの前に `f` を置き、埋め込みたい式を `{...}` で囲みます。

```python
order_id = 1001
status = "PAID"

message = f"order-{order_id}: {status}"
print(message)
```

```text
order-1001: PAID
```

`{order_id}` は `1001` に、`{status}` は `"PAID"` に置き換わります。  
数値を自分で文字列へ変換せずに埋め込める点も便利です。

## 数値を計算する

Python の基本的な算術演算子を確認します。

| 演算子 | 意味                           | 例              |
| ------ | ------------------------------ | --------------- |
| `+`    | 足す                           | `3 + 2` → `5`   |
| `-`    | 引く                           | `3 - 2` → `1`   |
| `*`    | 掛ける                         | `3 * 2` → `6`   |
| `/`    | 割り算                         | `7 / 2` → `3.5` |
| `//`   | 小数部分を下方向へ丸める割り算 | `7 // 2` → `3`  |
| `%`    | 割った余り                     | `7 % 2` → `1`   |
| `**`   | べき乗                         | `2 ** 3` → `8`  |

```python
subtotal = 350 * 2
average = 7 / 2
groups = 7 // 2
remainder = 7 % 2

print(subtotal)
print(average)
print(groups)
print(remainder)
```

```text
700
3.5
3
1
```

`/` は整数どうしでも小数の結果を返すため、平均や割合の計算に向いています。  
`//` は結果を超えない整数へ負の方向に丸めるため、7 個の商品から 2 個組をいくつ作れるか、といった「完成する組の数」を求める場面で使えます。

```python
print(-7 // 2)
```

```text
-4
```

負の数でも 0 に近づけるわけではないため、`-3` ではなく `-4` になります。

## 値を更新する

現在の値を使って計算し、その結果を同じ名前へ代入できます。

```python
quantity = 2
quantity = quantity + 1
quantity += 2

print(quantity)
```

```text
5
```

`quantity += 2` は、`quantity = quantity + 2` を短くした書き方です。  
同じように `-=`, `*=`, `/=` も使えます。

Python には `quantity++` のようなインクリメント演算子はありません。  
一つ増やす場合も `quantity += 1` と書きます。

## 値を比較する

比較の結果は `True` または `False`、つまり `bool` 型の値になります。

| 演算子              | 意味               |
| ------------------- | ------------------ |
| `a == b`            | 等しい             |
| `a != b`            | 等しくない         |
| `a < b` / `a > b`   | より小さい／大きい |
| `a <= b` / `a >= b` | 以下／以上         |

```python
amount = 1200
is_bulk = amount >= 1000
is_paid = "PAID" == "PAID"

print(is_bulk)
print(is_paid)
```

```text
True
True
```

`=` は代入、`==` は値が等しいかの比較です。  
見た目は似ていますが、役割は異なります。

## よくあるつまずき

- 比較する場所で `=` を使う（値が等しいかの比較は `==`）
- `True`、`False`、`None` を小文字で書く
- `/` と `//` の結果を取り違える
- Python に `++` があると思い、`quantity++` と書く
- f-string の先頭に `f` を付け忘れ、`{order_id}` がそのまま表示される
- 一つの名前へ異なる型の値を次々に代入し、役割を追いにくくする

## まとめ / 次に学ぶとよいこと

- `=` は値を名前へ結び付ける代入で、名前は別の値へ再代入できる
- 主な値の型には `int`、`float`、`str`、`bool` があり、値なしは `None` で表す
- f-string は `f"order-{order_id}"` のように値を文字列へ埋め込む
- `/` は通常の割り算、`//` は下方向へ丸める割り算、`%` は余りを求める
- `+=` で現在の値へ加算し、`==` や `!=` などで値を比較する
