# ジェネリクスと Protocol

入力が `str` なら返り値も `str`、入力が `int` なら返り値も `int` と伝えたい。  
また、継承関係ではなく「必要なメソッドを持つもの」を受け取りたいこともあります。  
ジェネリクスと `Protocol` は、この型の関係と振る舞いを表します。  

## このページで分かること

- `TypeVar` で入力と出力の型を結ぶ方法
- `Generic` を使うクラスの読み方
- `Protocol` で必要な振る舞いを表す方法

## TypeVar で型の関係を保つ

引数と返り値をどちらも `object` と書くと、「何らかの値を受け取り、何らかの値を返す」ことしか伝わりません。  
`TypeVar` は、呼び出しごとに決まる型へ仮の名前を付け、入力と出力が同じ型だという関係を保ちます。  

```python
from typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]

name = first(["Aiko", "Ren"])
score = first([80, 95])
```

型チェッカーは `name` を `str`、`score` を `int` と推論します。  
`T` は特定の一種類を表す名前ではなく、同じ呼び出しの中で同じ型になる場所を結び付ける型変数です。  
なお、空リストで起きる `IndexError` は型ヒントとは別に対処が必要です。

## ジェネリックなクラス

型変数を使って、中に入れる値の型を保つクラスを **ジェネリックなクラス** と呼びます。  

```python
from typing import Generic, TypeVar

T = TypeVar("T")

class Box(Generic[T]):
    def __init__(self, value: T) -> None:
        self.value = value

    def get(self) -> T:
        return self.value
```

`Box("Aiko")` は `Box[str]` と推論され、`get()` の返り値も `str` になります。  
`Box[int]` なら整数を保持する箱、`Box[str]` なら文字列を保持する箱というように、同じクラスで中身の型を保てます。  
一つの `Box` に何でも混ぜるためではなく、利用時に決まった中身の型を、その後の操作まで伝えるための仕組みです。  

## Protocol で振る舞いを表す

関数が必要としているのが `close()` だけなら、特定のクラスを継承していることまで要求する必要はありません。  
`Protocol` には、利用側が必要とする属性やメソッドの形を書きます。  

```python
from typing import Protocol

class Closable(Protocol):
    def close(self) -> None:
        ...

def finish(resource: Closable) -> None:
    resource.close()

class Connection:
    def close(self) -> None:
        print("closed")

finish(Connection())
```

`Connection` は `Closable` を継承していませんが、必要な形の `close` を持つため適合します。  
このように、明示的な継承ではなく持っている操作の形で適合を判断します。この考え方を **構造的部分型** と呼びます。  
利用側は具体的なクラスに縛られないため、本番用の接続とテスト用の代用品を同じ関数へ渡しやすくなります。  

:::tip[必要な操作だけを書く]

Protocol には利用側が実際に使う最小限の属性とメソッドを書きます。実装の差し替えやテストがしやすくなります。  

:::

## よくあるつまずき

- 関係を保ちたい入力と返り値を別々の型変数にして、つながりを失う
- `TypeVar` を実行時に値を検査する仕組みだと考える
- `Protocol` に利用しないメソッドまで並べ、実装側へ不要な条件を課す
- 型が安全なら空リストなどの実行時エラーも起きないと思う

## まとめ

- `TypeVar` は入力と出力などの型の関係を保つ
- `Generic[T]` は要素型を保つクラスを表す
- `Protocol` は継承ではなく必要な振る舞いを約束にする
