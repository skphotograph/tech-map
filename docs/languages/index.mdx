# 言語

主要なプログラミング言語の教材をまとめるカテゴリです。  
コード例は、架空の **EC サイト**（商品・カート・注文・在庫）を題材にそろえています。  
言語が変わっても同じ場面で比べられるので、「変数は数量、クラスは注文票」といった感覚を持ちやすくなります。

## 章一覧

- [Python](./python/) … 書き方の入口から、型ヒント、依存管理、アプリ部品まで
- [Java](./java/) … 書き方の入口から、メモリ・ビルド・設計・アプリ部品まで
- [JavaScript / TypeScript](./javascript-typescript/) … JavaScript の実行と非同期、TypeScript、npm、アプリ部品まで
- Rust

## おすすめの学び方

まずは興味のある [Python](./python/)、[Java](./java/)、[JavaScript / TypeScript](./javascript-typescript/) から進められます。  
[共通基盤](../foundations/) の Git や Linux を触ったあとに読むと、ビルドや調査の話がつながりやすいです。
