# Java をはじめよう

この章では、業務システムでもよく使われる言語 **Java** を学びます。  
ゴールは文法の暗記ではなく、レビュー、障害調査、フレームワーク学習で必要になる **言語の定番・実行の仕組み・メモリ・ビルド・設計の入口** をつなげて理解することです。  
例は架空の EC サイト（商品・注文・在庫）でそろえ、現場でよく出るデータの形に寄せています。

## この章の進め方

共通基盤の Git や Linux と同じく、**書き方の入口から** 積み上げます。  
入門編（ロードマップ **1〜17**）で、教科書レベルの言語と定番 API を一通り押さえてから、**18 以降**（実行モデル・型とメモリ・深掘り）へ進みます。

入門編で押さえること:

- 変数・型・四則演算、文字列の `equals`、`if` / `for`、メソッドの定義と呼び出し
- 起動引数・入力・数値への変換（`args` / `Scanner` / `parseInt`）
- `class` を書いて `new` する、フィールドの初期値と `null` の入口
- アクセス修飾子、getter と意味のある窓口メソッド、配列と `List`
- 複数ファイルと `package`
- **static / final**、**継承 / インタフェース**、**例外**、**コレクション / ジェネリクス**、**ラムダ / Stream / Optional** の入口

本編（18 以降）で厚く扱うこと:

- コンパイル、JVM、クラスパス（実行モデル）
- 値と参照、スタックとヒープ、値渡し
- 文字列プールと `hashCode` 契約、GC・リーク調査
- ジェネリクス深掘り、Stream / Collector、日時、ファイル、JDBC、並行処理、JVM 内部

:::info[読み方の目安]

はじめて近い人は、[Java 言語](./basics/) の **入門編**（1〜17）を順に通してから、[実行の仕組み](./basics/execution-model) 以降へ進んでください。  
すでに入門文法が手に馴染んでいる人は、1〜12 を流し読みし、13〜17 と 18 以降の穴がないか確認してください。

:::

## この章で分かること

- 小さな Java プログラムを書いて動かす入口
- static、継承、例外、コレクション、ラムダなど言語の定番
- Java がどうコンパイルされ、JVM 上で動くか
- 値と参照、ガベージコレクション、並行処理、現代的な API の使いどころ
- Maven による依存管理とビルドの考え方
- OOP と設計原則の入口、Web アプリ寄りの中立的な部品（DI・REST・データアクセスなど）

## こんな場面で効く

「リストを渡したのに、呼び出し元まで中身が変わっている」  
「エラーが出たのに、どの行が原因か追えない」  
「同じ文字列なのに `==` と `equals` で結果が違う」  
「`java` を実行したのに、クラスが見つからないと言われる」

土台が見えていると、ライブラリやサーバの話が「魔法」ではなくなります。  
道具の使い方と、倉庫の地図がつながる、という感覚です。

:::tip[この章のゴール]

入門範囲を書ける状態のあと、メモリと実行のイメージを持ち、ビルドと依存の感覚を持ったうえで、Web アプリでよく出る部品を中立的に説明できる状態を目指します。

:::

## 学習のロードマップ

1. [Java 言語](./basics/) … 入門編（1〜17）、実行モデル、メモリと GC、深掘り API、JDBC、並行処理
2. [Maven](./maven/) … 依存解決とビルドの標準的な道具
3. [設計の入口](./design/) … OOP・原則・アーキテクチャの見取り図
4. [アプリケーション部品](./applications/) … DI・REST・データアクセスなどをスタック非依存で整理

フレームワークは特定製品に寄せません。  
Jakarta EE も Spring も、現場ではどちらも出てきます。  
ここでは共通する考え方を先に持ち、各スタックの細部は公式ドキュメントや配属先の案内に任せます。

[共通基盤](../../foundations/)（Git / Linux など）を先に読んでおくと、コマンド例や調査の型が追いやすいです。  
HTTP の用語は共通基盤側の章が揃うまでのあいだ、[REST API と DTO](./applications/rest-and-dto) の最低限の表でも足ります。
