# Java をはじめよう

Java のコードを書くだけでなく、ビルドし、設計し、アプリケーションとして組み立てるところまで学ぶ章です。  
言語、Maven、設計、アプリケーション部品の 4 つに分け、基礎から順に進みます。

## この章の進め方

1. [Java 言語](./basics/) … 書き方の入門から、実行・メモリ・標準 API まで
2. [Maven](./maven/) … 依存解決とビルドの標準的な道具
3. [設計の入口](./design/) … OOP・原則・アーキテクチャの見取り図
4. [アプリケーション部品](./applications/) … DI・REST・データアクセスなどをスタック非依存で整理

まず [Java 言語](./basics/) を通し、その後は上から順に進むと、コードの書き方とビルド・設計・アプリケーション構成がつながります。  
Java 言語内の詳しい順序と入門編の範囲は、リンク先のロードマップにまとめています。

## この章で目指すこと

- Java のコードを読み書きし、実行時の問題を調べられる
- Maven で依存関係とビルド手順を管理できる
- クラスの責務や依存関係を、基本的な設計原則に沿って考えられる
- DI・REST・データアクセスなど、Web アプリで使う部品の役割を説明できる

特定のフレームワークの操作を覚えることが目的ではありません。  
Jakarta EE や Spring などで共通する考え方を押さえ、採用する技術が変わっても判断に使える土台を作ります。

[共通基盤](../../foundations/)（Git / Linux など）を先に読んでおくと、コマンド例や調査の型が追いやすいです。  
HTTP の用語は共通基盤側の章が揃うまでのあいだ、[REST API と DTO](./applications/rest-and-dto) の最低限の表でも足ります。
