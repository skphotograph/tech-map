# 配列と List

同じ型の値を、まとめて前から触りたいことがあります。  
件数固定なら **配列**、あとから増えやすいなら **List** がよく使われます。

[繰り返し](./loops) の `for` と、[クラスと new](./classes) の `new` が材料になります。

## このページで分かること

- 配列の作り方、添字、`length`
- 拡張 for で一覧を前から触る
- 前置インクリメントと後置インクリメント（添字と組み合わせるとき）
- `List` の入口（`add` / `get` / `size`）と `import`
- 配列と `List` の使い分けの目安

## 配列: 決まったマスのトレー

卵パックのように、**マス数は最初に決まる** イメージです。

```java
int[] quantities = new int[3];
quantities[0] = 10;
quantities[1] = 20;
quantities[2] = 30;

System.out.println(quantities.length); // 3
System.out.println(quantities[1]);     // 20
```

- `int[]` … 整数の配列という型
- `new int[3]` … マスが 3 つのトレーを用意する
- 番号（添字）は **0 から**（最初のマスが 0）
- `length` … マスの数（メソッド呼び出しではない。括弧は付けない）
- 無いマスを触ると実行時エラーになる

リテラルで一気に入れる書き方もあります。

```java
int[] quantities = {10, 20, 30};
```

:::tip[覚えておくこと]

配列の添字は 0 始まり。  
長さは `length`。あとからマスは増やせない。

:::

通常の `for` で回す例です。

```java
for (int i = 0; i < quantities.length; i++) {
    System.out.println(quantities[i]);
}
```

## 前置と後置: 添字と一緒に使うとき

[変数と計算](./variables-and-calculation) では、`i++` を「1 増やす略記」として見ました。  
[繰り返し](./loops) の `for` 更新欄では、`i++` も `++i` も回数は同じでした。

差が出るのは、**増やした値／増やす前の値を、その場で使う** ときです。  
配列の添字と組み合わせると、わかりやすいです。

| 書き方 | 名前（ざっくり）   | 動き                                        |
| ------ | ------------------ | ------------------------------------------- |
| `++i`  | 前置インクリメント | **先に** 1 増やしてから、その新しい値を使う |
| `i++`  | 後置インクリメント | **いまの値を使ってから**、あとで 1 増やす   |

切手の番号を読む前に進めるか、読んだあとに進めるか——その違いです。

まず、代入だけで差を見ます。

```java
int i = 0;
int x = i++; // x は 0、i は 1（渡してから増やす）
int j = 0;
int y = ++j; // y も j も 1（増やしてから渡す）
```

配列の添字と組み合わせると、同じ差がマス番号に出ます。

```java
int[] values = {10, 20, 30};
int i = 0;

int a = values[i++]; // 添字 0 を使う → 10。そのあと i は 1
int b = values[++i]; // 先に i を 2 にしてから使う → 30
```

この例では、差を見せるために添字 1（値 20）は使っていません。  
「飛ばした」のではなく、前置と後置のタイミングの違いです。

`--i` / `i--` も、「減らすタイミング」が前後する点は同じです。

:::tip[覚えておくこと]

`i++` は「今の番号で触ってから進む」。  
`++i` は「進んでから触る」。  
読みやすさのため、添字の中に `i++` をねじ込むのは避け、更新は別の文や `for` の更新欄に置くことが多いです。

:::

## 拡張 for: 棚を左から一冊ずつ

添字が不要なときは、拡張 for（for-each）が読みやすいです。  
棚の本を、左から一冊ずつ手に取るイメージです。

```java
String[] statuses = {"OPEN", "CLOSED"};
for (String status : statuses) {
    System.out.println(status);
}
```

出力例:

```text
OPEN
CLOSED
```

- `:` の右が一覧、左が「いま手に取っている 1 件」
- 添字 `i` を自分で増やさなくてよい

## List: あとから入れられる袋

追加や件数が変わりやすい一覧は、配列より `List` の方が扱いやすいことが多いです。  
卵パック（固定）ではなく、**買い物袋** に近いです。

```java
import java.util.ArrayList;
import java.util.List;

public class StatusListDemo {
    public static void main(String[] args) {
        List<String> statuses = new ArrayList<>();
        statuses.add("OPEN");
        statuses.add("CLOSED");
        System.out.println(statuses.size()); // 2
        System.out.println(statuses.get(0)); // OPEN
    }
}
```

ファイルの先頭付近に書く `import` は、「ほかの引き出しにある道具を借りる」宣言です。  
この 2 行があると、`List` / `ArrayList` が書けます。

`List<String>` の `<String>` は、「この袋に入れるのは文字列」という約束です。  
`new ArrayList<>()` の `<>` は、「左と同じ型で作る」短い書き方です。  
今はこの約束が読めれば十分です。

| 操作           | 意味（ざっくり）     |
| -------------- | -------------------- |
| `add(...)`     | 末尾に入れる         |
| `get(添字)`    | 取り出す（0 始まり） |
| `size()`       | いまの件数           |
| `List<String>` | 文字の並びを入れる袋 |

`List` も拡張 for で回せます。

```java
for (String status : statuses) {
    System.out.println(status);
}
```

:::info[書き方の入口]

`List` と `ArrayList` の細かい違いや、別の種類の一覧は、まだ出てきません。  
いまは「可変長の一覧がある」と分かれば十分です。

:::

## 配列と List の目安

| 向き                   | 選びやすいもの |
| ---------------------- | -------------- |
| 長さが最初から固定     | 配列           |
| 追加・削除が起きやすい | `List`         |
| とりあえず可変の一覧   | `List` が多い  |

## よくあるつまずき

- 添字を 1 始まりだと思ってずれる
- `length` に `()` を付けてしまう／`size` に付け忘れる
- 配列の長さをあとから変えようとする
- `values[i++]` と `values[++i]` を取り違え、読むマスがずれる
- `import` を忘れて `List` が解決しない

## まとめ / 次に学ぶとよいこと

- 配列は固定長。添字は 0 始まり。長さは `length`
- `i++` は使ってから増やす、`++i` は増やしてから使う（添字と組み合わせると差が見える）
- 拡張 for で「今の 1 件」を前から触れる
- `List` は追加しやすい一覧。`import` が必要
