# 変数と制御構文

プログラムは、ずっと同じ一文を繰り返すだけでは仕事になりません。  
「個数を覚えておく」「条件で道を選ぶ」「同じ作業を回数だけ回す」——この三つがそろうと、突然コードが読みやすくなります。  
演算子の一覧や、すべての制御構文を覚える必要はありません。

## このページで分かること

- 変数（名前付きのメモ）の書き方
- よく使う型の入口（`int` / `boolean` / `String`）
- 比較と簡単な演算、`i++`
- `if` による分岐
- `for` による繰り返し

## 変数は「名前の付いた付箋」

カフェのカウンターで、注文を口頭だけだとすぐ忘れます。  
「ホット L」「テイクアウト」と付箋に書いて貼ると、あとの人が迷いません。  
プログラムでも、途中の値には **名前付きの付箋（変数）** を付けます。

```java
int cups = 3;
boolean takeout = true;
String drink = "latte";
```

- 左が **型**（どんな付箋か）、右が入れる **値**
- `=` は「等しい？」ではなく **書き込み**（付箋の中身を入れる／貼り替える）

型の入口だけ挙げます。

| 型        | 付箋の種類         | 例                  |
| --------- | ------------------ | ------------------- |
| `int`     | 整数のメモ         | `3`, `0`, `-1`      |
| `boolean` | はい／いいえのメモ | `true`, `false`     |
| `String`  | 文字の並びのメモ   | `"latte"`, `"OPEN"` |

`String` は、ダブルクォート（`"..."`）で囲んだ文字の並びです。

```java
int cups = 3;
cups = cups + 1; // 4 になる（付箋を貼り替え）
```

同じ名前の付箋でも、中身はあとから書き換えられます。  
「3 杯だった注文に、もう 1 杯足した」イメージです。

## 比較と簡単な演算

分岐や繰り返しの条件では、「比べる」がよく出ます。  
料金テーブルを見るときと同じです。

| 書き方              | 意味（ざっくり）   |
| ------------------- | ------------------ |
| `a == b`            | 等しい             |
| `a != b`            | 等しくない         |
| `a < b` / `a > b`   | より小さい／大きい |
| `a <= b` / `a >= b` | 以下／以上         |

```java
int yen = 1200;
boolean bulk = yen >= 1000; // true（1000 円以上ならまとめ買い扱い、など）
```

整数の足し引きは `+` / `-` です。  
1 だけ増やすときは、次の略記もよく出ます。

```java
int i = 0;
i++; // i = i + 1 と同じ。i は 1 になる
```

スタンプカードに「もう 1 回押す」のが `i++` です。  
まずは **`i = i + 1` の短い書き方** と覚えておけば足ります。

このページの比較は、数値や `boolean` 向けです。

## 分岐: `if`

条件が成り立つときだけ動かす処理は、`if` で書きます。  
駅の改札で「切符が有効なら通る／だめなら別の案内」と同じです。

```java
int yen = 1200;

if (yen >= 1000) {
    System.out.println("bulk");
} else {
    System.out.println("normal");
}
```

- 条件は「はい／いいえ」になる式（ここでは `yen >= 1000`）
- `{ ... }` の中が、その道で実行される文
- `else` は「そうでなければ」

まずは「条件を見て、どちらの塊に入るか」が追えれば十分です。

枝を増やすときは `else if` を使います。  
サイズ選びのメニュー表に近いです。

```java
int yen = 500;

if (yen >= 1000) {
    System.out.println("bulk");
} else if (yen >= 100) {
    System.out.println("normal");
} else {
    System.out.println("small");
}
```

## 繰り返し: `for`

同じ作業を「決まった回数」やる定番が `for` です。  
朝のラジオ体操を 3 回やる、のイメージです。

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

出力例:

```text
0
1
2
```

読み方です。

1. `int i = 0` … 回数カウンタを 0 から始める
2. `i < 3` … 「まだ 3 回未満なら続ける」
3. `i++` … 一周ごとにカウンタを 1 増やす
4. 中の文を、条件がはいのあいだ繰り返す

<details>
<summary>while もある</summary>

条件が続くあいだ回す `while` もあります。

```java
int n = 3;
while (n > 0) {
    System.out.println(n);
    n = n - 1;
}
```

回数より「終わる条件」が主役のときに使います（例: 在庫が残っているあいだ取り出す）。  
まずは `for` が読めれば十分です。

</details>

:::tip[覚えておくこと]

変数は名前付きの付箋。  
`if` で道を選び、`for` で回数付きの繰り返しを書く。  
`i++` は `i = i + 1` の略記。

:::

## まとめ / 次に学ぶとよいこと

- 変数には型があり、`=` で中身を貼り替える
- 比較は `==` / `!=` / `<` / `>` など、増分は `i++` も使う
- `if` / `else` で条件分岐する
- `for` でカウンタ付きの繰り返しを読む
