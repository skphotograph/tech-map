# 条件分岐

同じプログラムでも、状況によって動きを変えたいことがあります。  
「1000 円以上ならまとめ買い」「そうでなければ通常」——道を選ぶ書き方が **条件分岐** です。

[変数と計算](./variables-and-calculation) の比較（`>=` など）が、ここで材料になります。

## このページで分かること

- `if` / `else` でふたつの道を選ぶ
- `else if` で枝を増やす
- 三項演算子で「どちらかの値」を一文で選ぶ
- `switch` 文で決まった候補ごとに道を選ぶ
- 条件は `boolean`（はい／いいえ）になる式であること
- `&&` / `||` / `!` で条件を組み合わせる入口

## `if` / `else`: 改札のふたつの道

駅の改札で、「切符が有効なら通る／だめなら別の案内」と同じです。

```java
int yen = 1200;

if (yen >= 1000) {
    System.out.println("bulk");
} else {
    System.out.println("normal");
}
```

読み方です。

1. `yen >= 1000` を調べる（結果は `true` か `false`）
2. `true` なら最初の `{ ... }` へ
3. `false` なら `else` の `{ ... }` へ

`else` は省略できます。  
「条件がはいのときだけ動かす」書き方です。

```java
if (yen >= 1000) {
    System.out.println("bulk");
}
```

:::tip[覚えておくこと]

`if` の丸括弧の中は、はい／いいえになる式。  
波括弧 `{ }` の中が、その道で実行する文。

:::

## `else if`: メニュー表のように枝を増やす

ふたつでは足りないとき、`else if` で枝を増やします。  
サイズ選びのメニュー表に近いです。

```java
int yen = 500;

if (yen >= 1000) {
    System.out.println("bulk");
} else if (yen >= 100) {
    System.out.println("normal");
} else {
    System.out.println("small");
}
```

上から順に調べ、**最初に当てはまった枝だけ** が動きます。  
`500` は 1000 以上ではないが 100 以上なので、`"normal"` です。

順番を間違えると、意図と違う枝に入ります。  
厳しい条件（大きい金額など）を先に書くことが多いです。

## 三項演算子: どちらかの値を一文で

「条件がはいなら A、いいえなら B」を **値として** ほしいとき、三項演算子が使えます。  
`if` / `else` で変数に代入するのと同じことを、短い式で書きます。

```java
int yen = 1200;
String label = yen >= 1000 ? "bulk" : "normal";
System.out.println(label); // bulk
```

読み方は左から次のとおりです。

1. `yen >= 1000` … 条件
2. `?` の直後 … はいのときの値（`"bulk"`）
3. `:` の直後 … いいえのときの値（`"normal"`）

```java
// 同じ意味の if / else
String label;
if (yen >= 1000) {
    label = "bulk";
} else {
    label = "normal";
}
```

短い二択の代入には便利です。  
`?` と `:` を何段も重ねると読みにくくなるので、枝が増えたら普通の `if` に戻します。

## `switch` 文: ロッカーの番号で開ける

「いくつ以上か」ではなく、**決まった候補のどれか** で道を選びたいときがあります。
注文の状態が `"OPEN"` / `"PAID"` / `"CLOSED"` のどれか、のようにです。  
ロッカーの番号を見て、その扉だけ開けるイメージが `switch` 文です。

```java
String status = "PAID";

switch (status) {
    case "OPEN":
        System.out.println("edit");
        break;
    case "PAID":
        System.out.println("ship");
        break;
    case "CLOSED":
        System.out.println("archive");
        break;
    default:
        System.out.println("unknown");
        break;
}
```

出力例:

```text
ship
```

読み方です。

1. `switch (status)` … 比べる値を決める
2. `case "PAID":` … その値のとき、ここから実行する
3. `break;` … この枝で終わり、`switch` を抜ける
4. `default:` … どの `case` にも当てはまらないときの受け皿（省略可）

`else if` の連打でも書けますが、候補がはっきりしているときは `switch` の方が追いやすいことが多いです。  
逆に「1000 円以上」のような範囲の比較は、`if` の方が向きます。

:::warning[break を忘れない]

`break` が無いと、当てはまった `case` のあと、次の `case` へ落ち続けます（フォールスルー）。  
意図しない動きになりやすいので、入門では **各枝の末尾に `break`** を付ける癖にします。

:::

```java
int code = 1;

switch (code) {
    case 1:
        System.out.println("one");
        // break が無い
    case 2:
        System.out.println("two");
        break;
    default:
        System.out.println("other");
        break;
}
```

この例では `one` のあとに `two` も出ます。  
「1 のときだけ one」が欲しいなら、`break` が必要です。

複数の候補で同じ処理にしたいときは、`case` を並べられます。

```java
switch (status) {
    case "OPEN":
    case "REVIEW":
        System.out.println("active");
        break;
    default:
        System.out.println("other");
        break;
}
```

:::tip[覚えておくこと]

`switch` は「この値ならこの扉」。  
各扉の終わりに `break`。どれでもないときは `default`。

:::

## 条件を組み合わせる

複数の条件を同時に見たいときは、次を使います。

| 書き方     | 意味（ざっくり）     |
| ---------- | -------------------- |
| `a && b`   | 両方はいならはい     |
| `a \|\| b` | どちらかはいならはい |
| `!a`       | はい／いいえを反転   |

```java
int yen = 1200;
boolean member = true;

if (yen >= 1000 && member) {
    System.out.println("member-bulk");
}

if (yen < 0 || yen > 1_000_000) {
    System.out.println("out-of-range");
}

boolean closed = false;
if (!closed) {
    System.out.println("accepting");
}
```

まずは「かつ」「または」「ではない」が読めれば足ります。  
複雑な条件は、名前付きの `boolean` に一度入れてから `if` すると追いやすいです。

```java
boolean bulkMember = yen >= 1000 && member;
if (bulkMember) {
    System.out.println("member-bulk");
}
```

<details>
<summary>波括弧を省略する書き方</summary>

文が 1 つだけのとき、波括弧を省略できる構文もあります。  
読み違えやすいので、入門では **いつも `{ }` を付ける** 方が安全です。

</details>

## よくあるつまずき

- `=`（代入）を条件に書いてしまう（比較は `==`）
- `else if` の順番を逆にして、先の広い条件に吸われる
- 三項演算子を何段も重ねて読みにくくする
- `switch` で `break` を忘れ、次の `case` まで落ちる
- `&&` と `||` を取り違える
- 波括弧の対応がズレて、見た目と違う道が動く

## まとめ / 次に学ぶとよいこと

- `if` / `else` で道を選ぶ。条件は `boolean`
- `else if` で枝を増やし、上から最初の当たりだけが動く
- 短い二択の値選びは `条件 ? はい : いいえ`
- `switch` 文は決まった候補ごとの扉。各枝の末尾に `break`
- `&&` / `||` / `!` で条件を組み合わせられる
