# 最初のプログラム

Java は、画面に一行出すだけのコードにも `public class` や `public static void main(String[] args)` という長い定型が付いてきます。  
書いてある単語の意味を全部分かってからでないと動かしてはいけない気がして、最初の一歩が重くなる——Java の入口でよく起きることです。  
先に動かしてしまって構いません。定型はこの形のまま書き写し、コンパイルして、画面に一行出るところまでを通します。

## このページで分かること

- 手元に開発用の道具（JDK）があるかの確認
- 小さなプログラムのひな型の読み方
- コンパイルして実行する最短ルート

## なぜ最初に「動かす」か

Java は、書いたソースをそのまま実行しません。  
`javac` で機械が読める形に変換してから、`java` に渡して動かす二段構えです。  
そのため「動かない」ときの原因も、道具が入っていない・変換で止まった・実行の指定が違う、と分かれます。

先に成功する一往復を通しておけば、次に止まったときも、どの段で止まったのかが見当をつけられます。

## 道具箱を開ける（JDK の確認）

学習で使うのは **JDK** です。  
「書いて動かす一式」が入ったセットで、次のふたつが揃っているかが目安です。

```bash
java -version
javac -version
```

成功例（表示は環境によって違います）:

```text
openjdk version "17.0.x" ...
javac 17.0.x
```

| コマンド | たとえ           | やること                                   |
| -------- | ---------------- | ------------------------------------------ |
| `javac`  | 出荷前の梱包準備 | 人が書いたソースを、機械が読む形に変換する |
| `java`   | 出荷して動かす   | 変換済みのプログラムを実際に動かす         |

どちらかが見つからないときは、JDK を入れて PATH を通す必要があります。  
配布元のインストール手順に従い、入れ直したあとに同じコマンドをもう一度試してください。

:::tip[覚えておくこと]

学習では `java` と `javac` の両方が使える状態にする。  
片方だけ通っても、教材の手順は途中で止まります。

:::

## 注文確認を一行出す

次の内容を `OrderApp.java` として保存します。  
**ファイル名** と、中の `public class` の名前は揃えます。  
玄関の表札と部屋の名前が一致していないと、配達が迷うのと同じです。

```java
public class OrderApp {
    public static void main(String[] args) {
        System.out.println("ORD-1001");
    }
}
```

### 定型を一行ずつほどく

入口の一行は長いですが、**いまは「この形で書く」と覚えて動けば十分**です。  
気になる単語だけ、ざっくり触れます。

| 部品                           | いまの読み方                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------ |
| `public class OrderApp`        | 「`OrderApp` というプログラムの箱を作る」宣言。ファイル名も `OrderApp.java` に揃える |
| `public static void main(...)` | 「ここから動き始める」と決まった書き方（起動の入口）                                 |
| `String[] args`                | 起動時に渡せる文字の並び用。今は空でもよい定型の一部                                 |
| `System.out.println(...)`      | 画面（標準出力）に一行出す                                                           |
| `{ ... }`                      | 実際に動く処理を書く場所                                                             |

`public` / `static` / `void` は、入口の定型に付いている部品だと見ておけば足ります。  
一字一句の意味は、あとから自然に積み上がります。

:::tip[覚えておくこと]

入口は `public static void main(String[] args)`。  
まずはこの形を「起動の定型」として丸ごと覚えておけば足ります。

:::

## 動かしてみる

ソースがあるディレクトリへ移動してから、次を実行します。

```bash
javac OrderApp.java
java OrderApp
```

成功すると、次のような一行が出ます。

```text
ORD-1001
```

流れをたとえで言うと、こうです。

1. `javac OrderApp.java` … ソース（`.java`）を梱包準備して、実行用の束（`OrderApp.class`）を作る
2. `java OrderApp` … 束の名前（クラス名）を指定して動かす。`.class` は付けない

IDE の実行ボタンを押す場合も、裏側では同じ入口（`main`）が呼ばれます。

<details>
<summary>うまく動かないとき</summary>

- `javac` が見つからない … 道具箱（JDK）が入っていないか、PATH が通っていないことが多いです
- `OrderApp` というクラスが見つからない … いまいるフォルダや、クラス名の指定を確認します
- ファイル名とクラス名が食い違う … 表札（`.java`）と部屋名（`public class`）を揃えます
- `java OrderApp.java` と書いてしまう … 学習の基本形は `javac` のあと `java OrderApp`（クラス名）です

</details>

## まとめ / 次に学ぶとよいこと

- 学習前に `java -version` と `javac -version` を確認する
- 小さなプログラムは「クラス + `main` + 出力」で始められる
- ファイル名と `public class` の名前を揃える（表札と部屋名）
- `javac` で梱包準備し、`java` でクラス名を指定して実行する

次は [変数と計算](./variables-and-calculation) で、値を置き・計算する書き方へ進みます。
