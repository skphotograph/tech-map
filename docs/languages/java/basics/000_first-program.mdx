# 最初のプログラム

初めてのプログラムは、うまく動かなくても「壊した」わけではありません。  
多くの場合は、道具が揃っていないか、決まった書き方から少しだけズレています。  
このページでは、いちばん短い一巡——書いて、動かして、画面に一行出す——までを一緒に通ります。

## このページで分かること

- 手元に開発用の道具（JDK）があるかの確認
- 小さなプログラムのひな型の読み方
- コンパイルして実行する最短ルート

## なぜ最初に「動かす」か

レシピだけ眺めて料理したことが無いと、「焦げたときの匂い」が想像しにくいのと似ています。  
教材のコードも同じで、一度手元で動かすと、エラーの出方がぐっと身近になります。

## 道具箱を開ける（JDK の確認）

学習で使うのは **JDK** です。  
料理でいうと「まな板も包丁も入ったセット」で、次のふたつが揃っているかが目安です。

```bash
java -version
javac -version
```

成功例（表示は環境によって違います）:

```text
openjdk version "17.0.x" ...
javac 17.0.x
```

| コマンド | たとえ         | やること                                   |
| -------- | -------------- | ------------------------------------------ |
| `javac`  | 下ごしらえ     | 人が書いたソースを、機械が読む形に変換する |
| `java`   | 盛り付けて出す | 変換済みのプログラムを実際に動かす         |

どちらかが見つからないときは、JDK を入れて PATH を通す必要があります。  
配布元のインストール手順に従い、入れ直したあとに同じコマンドをもう一度試してください。

:::tip[覚えておくこと]

学習では `java` と `javac` の両方が使える状態にする。  
片方だけ通っても、教材の手順は途中で止まります。

:::

## Hello を書く

次の内容を `Hello.java` として保存します。  
**ファイル名** と、中の `public class` の名前は揃えます。  
玄関の表札と部屋の名前が一致していないと、配達が迷うのと同じです。

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("hello");
    }
}
```

### 定型を一行ずつほどく

入口の一行は長いですが、**いまは「この形で書く」と覚えて動けば十分**です。  
気になる単語だけ、ざっくり触れます。

| 部品                           | いまの読み方                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------ |
| `public class Hello`           | 「`Hello` というプログラムの箱を作る」宣言。ファイル名も `Hello.java` に揃える |
| `public static void main(...)` | 「ここから動き始める」と決まった書き方（起動の入口）                           |
| `String[] args`                | 起動時に渡せる文字の並び用。今は空でもよい定型の一部                           |
| `System.out.println(...)`      | 画面（標準出力）に一行出す                                                     |
| `{ ... }`                      | 実際に動く処理を書く場所                                                       |

`public` / `static` / `void` は、入口の定型に付いている部品だと見ておけば足ります。  
一字一句の意味は、あとから自然に積み上がります。

:::tip[覚えておくこと]

入口は `public static void main(String[] args)`。  
まずはこの形を「起動の定型」として丸ごと覚えておけば足ります。

:::

## 動かしてみる

ソースがあるディレクトリへ移動してから、次を実行します。

```bash
javac Hello.java
java Hello
```

成功すると、次のような一行が出ます。

```text
hello
```

流れをたとえで言うと、こうです。

1. `javac Hello.java` … レシピ（`.java`）を下ごしらえして、配膳用の皿（`Hello.class`）を作る
2. `java Hello` … 皿の名前（クラス名）を指定して出す。`.class` は付けない

IDE の実行ボタンを押す場合も、裏側では同じ入口（`main`）が呼ばれます。

<details>
<summary>うまく動かないとき</summary>

- `javac` が見つからない … 道具箱（JDK）が入っていないか、PATH が通っていないことが多いです
- `Hello` というクラスが見つからない … いまいるフォルダや、クラス名の指定を確認します
- ファイル名とクラス名が食い違う … 表札（`.java`）と部屋名（`public class`）を揃えます
- `java Hello.java` と書いてしまう … 学習の基本形は `javac` のあと `java Hello`（クラス名）です

</details>

## まとめ / 次に学ぶとよいこと

- 学習前に `java -version` と `javac -version` を確認する
- 小さなプログラムは「クラス + `main` + 出力」で始められる
- ファイル名と `public class` の名前を揃える（表札と部屋名）
- `javac` で下ごしらえし、`java` でクラス名を指定して実行する

次は [変数と制御構文](./variables-and-control) で、値を置き・分岐し・繰り返す書き方へ進みます。
