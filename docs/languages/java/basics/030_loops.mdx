# 繰り返し

同じ作業を、手で何行もコピペするのはつらいです。  
「3 回出す」「在庫があるあいだ取り出す」——回す書き方が **繰り返し（ループ）** です。

[変数と計算](./variables-and-calculation) の `++` と、[条件分岐](./branching) の条件の感覚が材料になります。

## このページで分かること

- `for` で回数付きの繰り返しを書く・読む
- `while` で「続く条件」中心の繰り返しを書く
- ループの中でよく使うカウンタと終了条件
- `break` / `continue` の入口

## `for`: 決まった回数まわす

朝のラジオ体操を 3 回やる、のイメージです。

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

出力例:

```text
0
1
2
```

`for` の丸括弧は、役割が三つに分かれています。

| 位置 | 例          | 役割                           |
| ---- | ----------- | ------------------------------ |
| 1    | `int i = 0` | 最初に一度だけ。カウンタ開始   |
| 2    | `i < 3`     | 毎回の前に調べる。続く条件     |
| 3    | `i++`       | 一周のあとに実行。カウンタ更新 |

流れです。

1. `i` を 0 にする
2. `i < 3` がはいなら本体を実行
3. `i++` する
4. 2 に戻る。いいえなら終わる

カウンタは 0 始まりが多いです。  
「3 回」なら `i < 3`（0, 1, 2）と覚えると現場のコードと合いやすいです。

:::tip[覚えておくこと]

`for (開始; 続く条件; 更新)`。  
本体は、条件がはいのあいだ繰り返す。  
更新欄の `i++` と `++i` は、返した値を使わないので **ループ回数は同じ**（現場では `i++` が多い）。

:::

合計のように、ループの外の変数を更新することもあります。

```java
int sum = 0;
for (int i = 1; i <= 3; i++) {
    sum += i;
}
System.out.println(sum); // 6（1+2+3）
```

## `while`: 終わる条件が主役

回数より「まだ続くか」が主役のときは `while` が向きます。  
在庫が残っているあいだ取り出す、に近いです。

```java
int n = 3;
while (n > 0) {
    System.out.println(n);
    n = n - 1;
}
```

出力例:

```text
3
2
1
```

- 先頭で条件を調べ、はいなら本体
- 本体の中で、いつかはいいえになるよう状態を更新する

:::warning[終わらないループ]

条件がいつまでもはいのままだと、プログラムが止まりません。  
`while` では特に、「ループの中で何が減る／進むか」を意識します。

:::

<details>
<summary>do-while（あとで条件）</summary>

```java
int n = 0;
do {
    System.out.println(n);
    n++;
} while (n < 1);
```

本体を **少なくとも 1 回** 実行してから条件を見ます。  
入門の本線では、まず `for` と `while` で十分です。

</details>

## `break` / `continue`（入口）

ループを途中で抜けたり、次の周へスキップしたりできます。

```java
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue; // この周の残りを飛ばして次へ
    }
    if (i == 4) {
        break; // ループ全体を終了
    }
    System.out.println(i);
}
```

出力例:

```text
0
1
3
```

多用すると追いづらくなります。  
「ここで終わり」「この件は飛ばす」がはっきりしているときに使います。

## `for` と `while` の使い分け（目安）

| 向き                 | 選びやすいもの |
| -------------------- | -------------- |
| 回数が最初から分かる | `for`          |
| 「終わる条件」が主役 | `while`        |

どちらでも書ける場面は多いです。  
読み手が追いやすい方を選びます。

## よくあるつまずき

- `i <= 3` と `i < 3` で回数を一つずらす
- `while` の中でカウンタを更新し忘れ、終わらない
- `for (int i = ...)` で宣言した `i` を、ループの `{ }` の外でも使えると思い込む（そのループの外では使えない）
- `break` だらけにして、普通の `if` で足りる話を複雑にする

## まとめ / 次に学ぶとよいこと

- `for` は開始・条件・更新がそろった回数付きループ
- `while` は条件がはいのあいだ回す。更新を忘れない
- `for` の更新欄では `i++` も `++i` も回数は同じ
- `break` / `continue` は例外的な近道
