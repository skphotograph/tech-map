# Java 言語をはじめよう

この節では、まず **入門編** で言語の書き方と定番 API を一通り押さえ、そのあと **実行・参照の地図** と深掘りへ進みます。

:::info[読み方]

入門編（1〜17）は、変数・クラス・package から static / 継承 / 例外 / コレクション / ラムダ入口まで、初学者が最初に押さえる範囲を一通り扱います。  
はじめて近い人は **1〜17 を順に** 通してから、18（実行の仕組み）以降へ進んでください。  
手が動く人は流し読みでも構いません。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- static / final、継承、例外、コレクション、ラムダ・Stream・Optional の入口
- `.java` がどう `.class` になり、JVM 上で動くか（実行モデル）
- 値と参照、スタックとヒープ、GC とリーク調査
- ジェネリクス深掘り、日時、ファイル、JDBC、並行処理、アノテーション

## なぜ入門のあとに実行・メモリか

入門編だけでも小さなプログラムは書けます。  
それでも実務で最初に迷うのは、「書けたけど、なぜこうなるのか」という **実行と参照** の場面です。

- メソッドに渡したリストの中身が、呼び出し元まで書き換わる
- エラーが出たのに、どの呼び出しが原因か追えない
- `NullPointerException` の「どこが null だったのか」が追えない
- GC があるのにヒープが戻らず、「たぶんリーク」で止まる

入門で文法と定番 API に慣れてから、18〜19 で地図を持つと、以降の GC や障害調査が「暗記」になりにくいです。

:::tip[この節のゴール]

入門範囲を書ける状態のあと、型・参照・GC・並行処理の会話についていけ、標準 API の選択理由を説明できる状態を目指します。

:::
