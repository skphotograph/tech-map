# Java 言語をはじめよう

この節では、まず書き方の最低限をそろえ、そのうえで **値がどこにあり、いつまで生き、どう実行されるか** まで含めて Java を扱います。  
基礎の構文と、実務で効く標準 API・並行処理・JVM は分けずに一本の道です。

:::info[読み方]

最初の数ページは、変数・制御構文・クラスなど **書き方の最低限** です。  
すでに手が動く人は流し読みで構いません。不安なところだけ戻っても大丈夫です。  
そのあとが本編で、参照・メモリ・例外・標準 API の「なぜそう使うか」へ進みます。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- `.java` がどう `.class` になり、JVM 上で動くか
- スタックとヒープ、GC、参照が切れないときの調べ方
- `String` 比較、static / final、継承、例外、コレクション
- ジェネリクス、Stream、日時、ファイル、JDBC、並行処理
- アノテーションとクラスローディングの入口

## なぜ言語と実行をひと続きにするか

現場で最初につまずきやすいのは、構文そのものより次のような場面です。

- `NullPointerException` の「どこが null だったのか」が追えない
- 渡したリストの中身が、呼び出し元まで書き換わる
- GC があるのにヒープが戻らず、「たぶんリーク」で止まる
- フレームワークのアノテーションが、裏側で何をしているか想像できない

値と参照、到達可能性、クラスパスは別章にすると、障害のときに横断できません。  
ここで一度つなげておくと、あとから読む Maven やアプリケーション部品が「設定の暗記」になりにくいです。

:::tip[この節のゴール]

小さなクラスを動かし、型・参照・GC・例外・コレクションの会話についていけ、標準 API の選択理由を説明できる状態を目指します。

:::
