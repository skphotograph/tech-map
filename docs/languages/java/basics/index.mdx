# Java 言語をはじめよう

この節では、まず書き方の最低限をそろえ、**値と参照・実行の仕組み** を掴んだうえで、言語の骨格と標準 API へ進みます。

:::info[読み方]

最初の数ページは、変数・制御構文・クラスなど **書き方の最低限** です。  
たとえ話多めで噛み砕いているので、手が動く人は流し読みで構いません。不安なところだけ戻っても大丈夫です。  
はじめて近い人は、下のロードマップ **1〜8**（書き方の最低限）を先に通してください。  
9 以降は、書き方が固まってからで構いません。

:::

## この節で分かること

- 小さなプログラムを書いて動かす書き方の入口
- `.java` がどう `.class` になり、JVM 上で動くか
- 値と参照、スタックとヒープ、のちに GC とリーク調査
- `String` 比較、static / final、継承、例外、コレクション
- ジェネリクス、Stream、日時、ファイル、JDBC、並行処理
- アノテーションとクラスローディングの入口

## 書き方だけ覚えても、あとでつまずく場面

入門書は文法中心になりがちですが、実務で最初に迷うのは「書けたけど、なぜこうなるのか」です。

- メソッドに渡したリストの中身が、呼び出し元まで書き換わってしまう
- エラーが出たのに、どの行が原因か追えない
- 同じ文字列なのに `==` と `equals` で結果が違う

こういう場面は、`new` で作った値がどこに残るか、`java` がどのファイルを読むかといった **実行の仕組み** とセットで理解する必要があります。  
この節では書き方を覚えた直後にその地図を置き、あとから読む Maven やアプリ部品が「設定の暗記」になりにくいようにしています。

:::tip[この節のゴール]

小さなクラスを動かし、値と参照・例外・コレクションの会話についていけ、標準 API を選ぶ理由を説明できる状態を目指します。

:::
