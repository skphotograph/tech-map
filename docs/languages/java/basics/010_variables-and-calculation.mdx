# 変数と計算

プログラムは、途中の値を覚えておき、足したり割ったりしながら進めます。  
このページでは、**名前付きのメモ（変数）** と、よく使う型、四則演算を丁寧に押さえます。  
道を選ぶ・繰り返すは、次のページ以降です。

## このページで分かること

- 変数の宣言と代入（`=` は書き込み）
- よく使う型（整数・小数・真偽・文字・文字列）
- 四則演算と余り、増減の略記
- 数値の比較（分岐の準備）

## 変数は「名前の付いた付箋」

カフェのカウンターで、注文を口頭だけだとすぐ忘れます。  
「ホット L」「3 杯」と付箋に書いて貼ると、あとの人が迷いません。  
プログラムでも、途中の値には **名前付きの付箋（変数）** を付けます。

```java
int cups = 3;
boolean takeout = true;
String drink = "latte";
```

- 左が **型**（どんな付箋か）、右が入れる **値**
- `=` は「等しい？」ではなく **書き込み**（付箋の中身を入れる／貼り替える）

```java
int cups = 3;
cups = cups + 1; // 4 になる
```

同じ名前の付箋でも、中身はあとから書き換えられます。

:::tip[覚えておくこと]

`=` は代入（書き込み）。  
「左に、右の結果を入れる」と読む。

:::

## よく使う型

型は、「その付箋に何を書いてよいか」の約束です。  
整数の付箋に文字の並びを書くと、コンパイルが止まります。

| 型        | 持つもの         | 例                      |
| --------- | ---------------- | ----------------------- |
| `int`     | 整数（よく使う） | `0`, `3`, `-1`, `1_000` |
| `long`    | より大きな整数   | `1_000_000_000L`        |
| `double`  | 小数             | `1.5`, `0.1`, `3.0`     |
| `boolean` | はい／いいえ     | `true`, `false`         |
| `char`    | 文字 1 つ        | `'A'`, `'あ'`           |
| `String`  | 文字の並び       | `"latte"`, `"OPEN"`     |

ポイントです。

- `int` が整数の定番。件数・金額（円）・カウンタによく使う
- `long` は桁が大きくなりそうなとき（末尾に `L`）
- `double` は小数。ただし「お金の厳密な計算」は別の話になることが多い
- `boolean` は条件の結果を覚えるときに使う
- `char` はシングルクォート（`'A'`）、`String` はダブルクォート（`"hi"`）
- `String` はクラス（参照型）だが、入門では「文字の並びを入れる型」で十分

```java
int quantity = 2;
double price = 350.0;
boolean member = true;
char grade = 'A';
String item = "tea";
```

<details>
<summary>型が合わないとどうなるか</summary>

```java
int cups = "three"; // コンパイルエラー
```

付箋の種類と中身が合わないと、実行前に止まります。  
「動いてから気づく」より早いです。

</details>

## 四則演算

整数・小数に対する基本の計算です。

| 演算子 | 意味       | 例（`int`）   |
| ------ | ---------- | ------------- |
| `+`    | 足す       | `3 + 2` → `5` |
| `-`    | 引く       | `3 - 2` → `1` |
| `*`    | 掛ける     | `3 * 2` → `6` |
| `/`    | 割る       | `7 / 2` → `3` |
| `%`    | 割った余り | `7 % 2` → `1` |

```java
int subtotal = 350 * 2;     // 700
int change = 1000 - subtotal; // 300
int pairs = 7 / 2;          // 3（整数どうしの割り算は端数切り捨て）
int leftover = 7 % 2;       // 1
```

:::warning[整数の割り算]

`7 / 2` は `3.5` ではなく `3` になります。  
小数が欲しければ、どちらかを `double` にします（例: `7.0 / 2`）。

:::

文字列の `+` は「つなげる」意味になります。

```java
String label = "order-" + 1001; // "order-1001"
```

計算の順序は、だいたい算数と同じで、掛け割りが足し引きより先です。  
迷ったら括弧 `()` で囲みます。

```java
int total = 100 + 20 * 3;   // 160
int clear = (100 + 20) * 3; // 360
```

## 略記: `+=` と `++`

同じ付箋を更新するとき、略記がよく出ます。

```java
int cups = 3;
cups = cups + 1; // 4
cups += 1;       // 同じ意味で 5
cups++;          // 同じ意味で 6（1 だけ増やす）
cups--;          // 1 だけ減らす
```

| 書き方        | 意味（ざっくり）     |
| ------------- | -------------------- |
| `x += 2`      | `x = x + 2`          |
| `x -= 2`      | `x = x - 2`          |
| `x *= 2`      | `x = x * 2`          |
| `x /= 2`      | `x = x / 2`          |
| `x++` / `++x` | だいたい「1 増やす」 |
| `x--` / `--x` | だいたい「1 減らす」 |

まずは **`x++` は `x = x + 1` の短い書き方** と覚えておけば足ります。  
スタンプカードに「もう 1 回押す」イメージです。

## 比較（分岐の材料）

「大きい／等しい」を調べると、結果は `boolean` になります。  
次のページの `if` でそのまま使います。

| 書き方              | 意味               |
| ------------------- | ------------------ |
| `a == b`            | 等しい             |
| `a != b`            | 等しくない         |
| `a < b` / `a > b`   | より小さい／大きい |
| `a <= b` / `a >= b` | 以下／以上         |

```java
int yen = 1200;
boolean bulk = yen >= 1000; // true
```

このページの比較は、数値や `boolean` 向けです。  
文字列の中身の比べ方は、あとで別ページで扱います。

## よくあるつまずき

- `=`（代入）と `==`（等しい）を取り違える
- `int` どうしの割り算で小数を期待する
- `char` にダブルクォート、`String` にシングルクォートを使う
- 計算の順序を括弧なしで書いて意図と違う

## まとめ / 次に学ぶとよいこと

- 変数は型付きの付箋。`=` で中身を貼り替える
- `int` / `double` / `boolean` / `String` などを用途で選ぶ
- 四則演算は `+ - * /`、余りは `%`。整数の割り算は切り捨て
- `+=` や `++` は更新の略記。比較は `boolean` を返す
