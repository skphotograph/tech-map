# 変数と計算

注文金額として `1200` の様な値がコードに登場するとして、それがあちこちに現れてくると、それが単価なのか合計なのか分からなくなります。  
値に意味の分かる名前を付ければ、計算の意図をコードに残せます。  
ここでは、Java で値へ名前を付け、型を揃え、計算して比べるところまで進めます。

## このページで分かること

- 変数の宣言と代入（`=` は書き込み）
- よく使う型（整数・小数・真偽・文字・文字列）
- 四則演算と余り、増減の略記
- 数値の型変換（キャスト）の入口
- 数値の比較（分岐の準備）

## 変数は「名前の付いた付箋」

カートの画面で、数量や単価を口頭だけだとすぐ忘れます。  
「マグカップ」「2 個」「1200 円」と付箋に書いて貼ると、あとの処理が迷いません。  
プログラムでも、途中の値には **名前付きの付箋（変数）** を付けます。

```java
int quantity = 2;
boolean inStock = true;
String productName = "mug";
```

- 左が **型**（どんな付箋か）、右が入れる **値**
- `=` は「等しい？」ではなく **書き込み**（付箋の中身を入れる／貼り替える）

```java
int quantity = 2;
quantity = quantity + 1; // 3 になる
```

同じ名前の付箋でも、中身はあとから書き換えられます。

:::tip[覚えておくこと]

`=` は代入（書き込み）。  
「左に、右の結果を入れる」と読む。

:::

## よく使う型

型は、「その付箋に何を書いてよいか」の約束です。  
整数の付箋に文字の並びを書くと、コンパイルが止まります。

| 型        | 持つもの         | 例                      |
| --------- | ---------------- | ----------------------- |
| `int`     | 整数（よく使う） | `0`, `3`, `-1`, `1_000` |
| `long`    | より大きな整数   | `1_000_000_000L`        |
| `double`  | 小数             | `1.5`, `0.1`, `3.0`     |
| `boolean` | はい／いいえ     | `true`, `false`         |
| `char`    | 文字 1 つ        | `'A'`, `'あ'`           |
| `String`  | 文字の並び       | `"mug"`, `"OPEN"`       |

ポイントです。

- `int` が整数の定番。件数・金額（円）・カウンタによく使う
- `long` は桁が大きくなりそうなとき（末尾に `L`）
- `double` は小数
- `boolean` は条件の結果を覚えるときに使う
- `char` はシングルクォート（`'A'`）、`String` はダブルクォート（`"hi"`）
- `String` は文字の並びを入れる型

```java
int quantity = 2;
int unitPrice = 1200;
boolean inStock = true;
char grade = 'A';
String productName = "mug";
```

`int` / `long` / `double` / `boolean` / `char` は **プリミティブ型**（基本データ型）と呼ばれます。  
`String` は文字の並びを扱う型で、次のページで比較などの入口を見ます。

<details>
<summary>型が合わないとどうなるか</summary>

```java
int quantity = "two"; // コンパイルエラー
```

付箋の種類と中身が合わないと、実行前に止まります。  
「動いてから気づく」より早いです。

</details>

## 四則演算

整数・小数に対する基本の計算です。

| 演算子 | 意味       | 例（`int`）   |
| ------ | ---------- | ------------- |
| `+`    | 足す       | `3 + 2` → `5` |
| `-`    | 引く       | `3 - 2` → `1` |
| `*`    | 掛ける     | `3 * 2` → `6` |
| `/`    | 割る       | `7 / 2` → `3` |
| `%`    | 割った余り | `7 % 2` → `1` |

```java
int unitPrice = 1200;
int quantity = 2;
int subtotal = unitPrice * quantity; // 2400
int change = 3000 - subtotal;        // 600
int pairs = 7 / 2;                   // 3（整数どうしの割り算は端数切り捨て）
int leftover = 7 % 2;                // 1
```

:::warning[整数の割り算]

`7 / 2` は `3.5` ではなく `3` になります。  
小数が欲しければ、どちらかを `double` にします（例: `7.0 / 2`）。

:::

整数に戻したいときは、**キャスト**（型の変換の宣言）を使います。

```java
double price = 3.9;
int yen = (int) price; // 3（小数点以下は切り捨て）
```

`(int)` は「この値を `int` として扱う」という印です。  
桁が大きい `long` を `int` に落とすと、入りきらないことがあります。  
「勝手に小さくしてよいのか」を意識して使います。

<details>
<summary>自動で広がる変換と、情報が落ちる方向</summary>

整数を小数に入れるのは、だいたい問題になりません。  
`3` は `3.0` に広げられるだけで、元の情報がそのまま残るからです。  
このように、書く側が指定しなくても進む変換を暗黙的キャスト（暗黙の型変換）と呼びます。

```java
int quantity = 3;
double asDouble = quantity; // 3.0（キャスト不要）
```

逆に、小数を整数に詰めようとすると、小数点以下が捨てられます。  
「情報が落ちる変換をしてよいのか」をコード上で明示するために、キャストが必要になります。  
`(int)` のように自分で書く変換を明示的キャストと呼びます。

```java
double price = 3.9;
// int yen = price;      // コンパイルエラー（勝手に捨てさせない）
int yen = (int) price;   // 3（小数点以下は切り捨て）
```

「広がる方向は自動、狭まる方向は自分で宣言」と覚えると迷いにくいです。

</details>

文字列の `+` は「つなげる」意味になります。

```java
String label = "ORD-" + 1001; // "ORD-1001"
```

計算の順序は、だいたい算数と同じで、掛け割りが足し引きより先です。  
迷ったら括弧 `()` で囲みます。

```java
int total = 100 + 20 * 3;   // 160
int clear = (100 + 20) * 3; // 360
```

## 略記: `+=` と `++`

同じ付箋を更新するとき、略記がよく出ます。

```java
int quantity = 2;
quantity = quantity + 1; // 3
quantity += 1;           // 同じ意味で 4
quantity++;              // 同じ意味で 5（1 だけ増やす）
quantity--;              // 1 だけ減らす
```

| 書き方   | 意味（ざっくり） |
| -------- | ---------------- |
| `x += 2` | `x = x + 2`      |
| `x -= 2` | `x = x - 2`      |
| `x *= 2` | `x = x * 2`      |
| `x /= 2` | `x = x / 2`      |
| `x++`    | `x = x + 1`      |
| `x--`    | `x = x - 1`      |

まずは **`x++` は `x = x + 1` の短い書き方** と覚えておけば足ります。  
カートの数量を「もう 1 個足す」イメージです。

## 比較（分岐の材料）

「大きい／等しい」を調べると、結果は `boolean` になります。  
条件分岐の材料になります。

| 書き方              | 意味               |
| ------------------- | ------------------ |
| `a == b`            | 等しい             |
| `a != b`            | 等しくない         |
| `a < b` / `a > b`   | より小さい／大きい |
| `a <= b` / `a >= b` | 以下／以上         |

```java
int yen = 1200;
boolean bulk = yen >= 1000; // true
```

このページの比較は、数値や `boolean` 向けです。

## よくあるつまずき

- `=`（代入）と `==`（等しい）を取り違える
- `int` どうしの割り算で小数を期待する
- 小数を `(int)` したときに切り捨てになるのを忘れる
- `char` にダブルクォート、`String` にシングルクォートを使う
- 計算の順序を括弧なしで書いて意図と違う

## まとめ / 次に学ぶとよいこと

- 変数は型付きの付箋。`=` で中身を貼り替える
- `int` / `double` / `boolean` / `String` などを用途で選ぶ
- 四則演算は `+ - * /`、余りは `%`。整数の割り算は切り捨て
- 狭い型へ落とすときは `(int)` などのキャスト
- `+=` や `++` は更新の略記。比較は `boolean` を返す
