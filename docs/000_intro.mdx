# はじめに

**Tech Map** へようこそ。  
技術用語を一つずつ調べても、「仕事の中でどうつながるのか」「次に何を学べばよいのか」が見えないことがあります。

Tech Map は、自分が学んだ IT 技術を整理して置いたメモの集まりです。  
公式の教科書や体系的な教材サイトを目指しているわけではなく、同じ道を辿る人の行燈になれば十分だと思っています。  
下の表は分野ごとの入口です。いま身につけたい知識からたどってください。

## 分野

| カテゴリ                                 | 内容                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------ |
| [共通基盤](./foundations/)               | Linux / Shell、Git、リモートアクセス（SSH など）、ネットワーク基礎、HTTP |
| [言語](./languages/)                     | Python / Java、JavaScript / TypeScript、Rust                             |
| [データ](./data/)                        | SQL / RDB、NoSQL、メッセージング                                         |
| [クラウド](./cloud/)                     | GCP、AWS、Azure                                                          |
| [DevOps / コンテナ](./platform/)         | Docker、Kubernetes、OpenShift、CI/CD、IaC                                |
| [セキュリティ](./security/)              | 認証・認可、クラウドセキュリティ、OWASP 基礎                             |
| [AI](./ai/)                              | LLM 基礎、Prompt / RAG、エージェント、MLOps                              |
| [設計 / アーキテクチャ](./architecture/) | API 設計、マイクロサービス、テスト戦略                                   |

どこから始めるか迷ったら、まず [共通基盤](./foundations/) で Linux や Git など、分野をまたいで使う知識を押さえると進みやすくなります。  
学びたい言語が決まっている場合は、[Python](./languages/python/)、[Java](./languages/java/)、[JavaScript / TypeScript](./languages/javascript-typescript/) から始めても構いません。
