# はじめに

**Training** へようこそ。このサイトでは、IT技術に関する学習教材を包括的にまとめていきます。

| カテゴリ | 内容 |

| [共通基盤](./foundations/) | Linux / Shell、Git、ネットワーク基礎、HTTP |
| [言語](./languages/) | Java、JavaScript / TypeScript、Rust |
| [データ](./data/) | SQL / RDB、NoSQL、メッセージング |
| [クラウド](./cloud/) | GCP、AWS、Azure |
| [DevOps / コンテナ](./platform/) | Docker、Kubernetes、OpenShift、CI/CD、IaC |

| [設計 / アーキテクチャ](./architecture/) | API 設計、マイクロサービス、テスト戦略 |

各カテゴリは現時点では概要と章立てのみです。本編は今後追加していきます。
