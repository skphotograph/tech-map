# 権限

`Permission denied` は、シェル初心者が最初にぶつかる壁のひとつです。  
怖がる必要はありません。  
「誰が・何に対して・何を許されているか」を読む問題です。

## このページで分かること

- `ls -l` の権限表示の読み方
- オーナー・グループ・その他の区別
- `chmod` で権限を変える基本（自分の練習ファイルで）

## なぜ権限があるか

サーバは複数人・複数サービスが同居します。  
誰でもシステム設定を書き換えられたり、他人の秘密ファイルを読めたりしたら破綻します。  
権限は、その境界線です。

## `ls -l` を読む

```bash
cd ~/training-linux
ls -l notes/hello.txt
```

例:

```text
-rw-r--r-- 1 alex alex 12 Mar 3 10:06 notes/hello.txt
```

通常ファイルは `-`、ディレクトリは `d`、シンボリックリンクは `l` です（[シンボリックリンク](./symlinks)）。  
左端の 10 文字を分解します。

```text
- rw- r-- r--
│ │   │   └─ その他（others）
│ │   └───── グループ（group）
│ └───────── オーナー（owner）の権限
└─────────── 種別（`-` ファイル / `d` ディレクトリ / `l` シンボリックリンク）
```

各 3 文字は次の意味です。

| 記号 | 意味 |
| --- | --- |
| `r` | 読み取り（read） |
| `w` | 書き込み（write） |
| `x` | 実行（execute）／ディレクトリなら「中に入れる」 |
| `-` | その権限なし |

上の例 `-rw-r--r--` なら:

- オーナー … 読み書き可
- グループ … 読み取りのみ
- その他 … 読み取りのみ

その後ろの `alex alex` は、オーナー名とグループ名です。

:::tip[まず読む場所]

`Permission denied` が出たら、対象を `ls -l` で見ます。  
「自分はオーナーか」「必要な `r` / `w` / `x` が付いているか」を確認します。

:::

## ディレクトリの `x` が特別な理由

ファイルの `x` は「プログラムとして実行できるか」です。  
ディレクトリの `x` は「そのディレクトリに入れるか（パスとして通れるか）」に近い意味になります。

`r` だけあって `x` がないディレクトリは、中身の一覧や移動でつまずくことがあります。  
「ディレクトリなのに入れない」ときは、`x` を疑います。

## 権限を変える：`chmod`

`chmod` は、ファイルやディレクトリの権限を変更するコマンドです。  
自分の練習ファイルで試します。

```bash
chmod 600 notes/hello.txt
ls -l notes/hello.txt
```

例:

```text
-rw------- 1 alex alex 12 Mar 3 10:06 notes/hello.txt
```

`600` は数値モードです。  
オーナーだけ読み書き、グループとその他は不可、という意味になります。

### 数値の考え方

`r=4`、`w=2`、`x=1` を足します。

| 値 | 意味 |
| --- | --- |
| 7 | `rwx`（4+2+1） |
| 6 | `rw-`（4+2） |
| 5 | `r-x`（4+1） |
| 4 | `r--` |
| 0 | なし |

3 桁は「オーナー・グループ・その他」の順です。  
例:

- `644` … オーナー `rw-`、他は `r--`（設定ファイルでありがち）
- `600` … オーナーだけ `rw-`（秘密に近いファイル向き）
- `755` … オーナー `rwx`、他は `r-x`（実行ファイルや公開ディレクトリでありがち）

<details>
<summary>文字で指定する方法（`u+x` など）</summary>

```bash
chmod u+x notes/hello.txt
```

- `u` オーナー、`g` グループ、`o` その他、`a` 全員
- `+` 付与、`-` 削除、`=` 指定値に設定

数値でも文字でも、チームで使っている方に揃えれば大丈夫です。

</details>

:::warning[本番の権限は慎重に]

共有サーバで他人のファイルやシステム領域の権限を変えるのは危険です。  
この教材では `~/training-linux` 配下だけを対象にしてください。  
`chmod -R 777` のような「全部ゆるくする」は、学習でも本番でも避けるのが無難です。

:::

<details>
<summary>`chown` について</summary>

オーナー自体を変えるのが `chown` です。  
権限が足りない場合は管理者権限が必要なことが多く、環境のルールに従います。  
まずは `ls -l` と `chmod` の読み書きができれば十分です。

</details>

## よくあるつまずき

| 症状 | よくある原因 | 方向性 |
| --- | --- | --- |
| `Permission denied` | 読み/書き/実行の不足 | `ls -l` で誰のどのビットか確認 |
| スクリプトが実行できない | `x` が付いていない | `chmod u+x`（[シェルスクリプト](./shell-scripts) も参照） |
| ディレクトリに入れない | ディレクトリに `x` がない | ディレクトリ側の権限を見る |

## まとめ

- 権限は「誰が・何を・どこまで」の境界
- `ls -l` の左 10 文字を分解して読む
- 変更は `chmod`、ただし対象と影響範囲に注意
