# 実務での使い方

ここまでの部品を、現場でありがちな「困った」にどう当てるかをまとめます。  
新しいコマンドを増やすより、**確認の順番** を持つことが目的です。

## このページで分かること

- 調査の基本ループ
- ディスク・ログ・ネットワーク確認の入口コマンド
- やってはいけない操作と、次に学ぶとよいテーマ

## 調査の基本ループ

何かがおかしいときは、次の順が崩れにくいです。

1. **現在地とユーザー** … `pwd` / `whoami`
2. **対象はあるか** … `ls` / `find`
3. **中身やログの手がかり** … `less` / `tail` / `grep`
4. **権限か** … `ls -l`
5. **プロセスは生きているか** … `ps`
6. **コマンドや設定は見えているか** … `which` / `echo "$PATH"` / 環境変数

:::tip[先に地図を取る]

いきなり直しに入らず、いま分かる事実を短くメモする。  
「どこで・誰として・何を見て・何が返ったか」が揃うと、相談も自己解決も速くなります。

:::

## パターン別の入口

### ログを追う

```bash
# 最新を見る
tail -n 100 /path/to/app.log

# キーワードで絞る
grep -n ERROR /path/to/app.log | tail -n 50

# 種類を集計する
grep ERROR /path/to/app.log | sort | uniq -c | sort -nr | head
```

パスは環境の実際のログ位置に置き換えてください。  
練習では `~/training-linux/notes/app.log` で十分です。

### ディスクが怪しい

`df` は、ファイルシステム全体のディスク空き容量を見るコマンドです。

```bash
df -h
```

例:

```text
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   31G   17G  66% /
```

- `Use%` … 使用率の目安
- `Mounted on` … どこに見えているか

ディレクトリ単位の荒い見方:

```bash
du -sh ~/training-linux/*
```

例:

```text
4.0K    /home/alex/training-linux/archive
24K     /home/alex/training-linux/notes
8.0K    /home/alex/training-linux/scripts
```

`du` は「その配下の合計サイズ感」を見るコマンドです。

### 疎通の超入口（詳細はネットワーク章へ）

`curl` は、URL にリクエストを送って結果を受け取るコマンドです。

```bash
curl -I https://example.com
```

例（抜粋）:

```text
HTTP/2 200
content-type: text/html
```

`-I` はヘッダだけ取る指定で、「HTTP で応答があるか」のごく浅い確認です。  
IP や DNS、ポートの本質はネットワーク基礎で扱います。

サーバへ入る・ファイルを運ぶ手順は、[リモートアクセス](../remote-access/) でまとめています。

## 安全側のチェックリスト

- 消す・上書きする前に `ls` で対象を見る
- 本番パスで `rm -rf` や `chmod -R 777` を打たない
- 秘密情報をコマンド履歴に残さない
- 共有サーバでは、自分のホームと許可された作業場所以外を勝手に変えない
- 分からないプロセスを `kill -9` しない

:::warning[権限が強いほど確認を増やす]

`sudo` が使える環境でも、「なぜ必要か」「対象は何か」を言えない操作は延期する。  
便利さと影響範囲はセットです。

:::

<details>
<summary>`sudo` とは</summary>

一時的に管理者権限でコマンドを実行する仕組みです。  
パスワードやポリシーは環境依存です。  
使えるからといって常時使うものではなく、必要な操作に限定します。

</details>

## 学習の定着クイックメニュー

次を、見ずに再現できれば十分戦えます。

| 目的 | コマンドの核 |
| --- | --- |
| 現在地 | `pwd` `ls` `cd` |
| 編集 | `nano` / `vim` |
| リンク | `ln -s` `readlink` |
| 探す | `find` `grep` |
| つなぐ | `\|` `>` `>>` |
| 権限 | `ls -l` `chmod` |
| プロセス | `ps` `kill` |
| 環境 | `echo "$PATH"` `which` |
| 集計・置換 | `sort` `uniq` `cut` `sed` `wc` |
| 自動化 | 短い `.sh` |
