# 共通基盤

どの言語やクラウドを触るときにも効く、土台の操作と見方を置いています。  
画面の奥でファイルはどこにあるか、変更は誰が残したか、遠隔の箱へはどう入るか、サービスはなぜ届かないか。  
ここが弱いと、フレームワークを増やすほど、障害の夜に言葉が足りなくなります。

このカテゴリでは、端末と履歴、遠隔操作、そしてサービスがつながる道（ネットワークと HTTP）までを扱います。  
目的は資格の暗記ではなく、調査と実装のときに **自分で層を分けて説明できる** ことです。

## 章一覧

1. [Git](./git/) … 変更履歴を残し、チームで安全に共有する
2. [Linux / Shell](./linux/) … 端末で環境を読み、調査と自動化の土台を作る
3. [リモートアクセス](./remote-access/) … SSH で入り、SFTP / SCP でファイルを運ぶ
4. [ネットワーク基礎](./network/) … IP、ポート、DNS、経路と門、「繋がらない」の切り分け
5. [HTTP](./http/) … リクエストとレスポンス、メソッド、ステータス、HTTPS、API の実務

## おすすめの学び方

[Git](./git/) と [Linux / Shell](./linux/) はどちらからでも始められます。  
シェルに慣れたら [リモートアクセス](./remote-access/) で遠隔のサーバへ進むと、学習環境が実運用に近づきます。  
そのあと [ネットワーク基礎](./network/) と [HTTP](./http/) へ進むと、「届かない」と「届いたが失敗した」を混ぜずに済むようになります。
