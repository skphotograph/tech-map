# 共通基盤

学習の前提となる共通スキルをまとめるカテゴリです。  
どの言語やクラウドを触るときにも効く「土台」から順に身につけていきます。

## 章一覧

- [Git](./git/) … 変更履歴を残し、チームで安全に共有する
- [Linux / Shell](./linux/) … 端末で環境を読み、調査と自動化の土台を作る
- [リモートアクセス](./remote-access/) … SSH で入り、SFTP / SCP でファイルを運ぶ
- ネットワーク基礎
- HTTP

## おすすめの学び方

[Git](./git/) と [Linux / Shell](./linux/) はどちらからでも始められます。  
シェルに慣れたら [リモートアクセス](./remote-access/) で遠隔のサーバへ進むと、学習環境が実運用に近づきます。  
そのあとでネットワークと HTTP へ進むと、サービスがつながるイメージが掴みやすくなります。
