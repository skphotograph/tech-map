# リモートアクセスをはじめよう

サーバは、いつも自分の膝の上にあるわけではありません。  
クラウド上の Linux、検証機、踏み台越しの本番隣接環境——。  
そこに入る・ファイルを運ぶための基本が、**SSH** とファイル転送の考え方です。

この章では、[Linux / Shell](../linux/) で身につけた操作を、遠隔の相手に届ける側に踏み出します。  
IP や DNS の深い話はネットワーク基礎へ譲り、ここでは「つながる・運ぶ・安全に使う」に集中します。

## この章で分かること

- リモートログインとファイル転送が、なぜ実務の前提になるか
- SSH での接続、鍵の登録、踏み台経由の入口
- SCP / SFTP と、旧来の FTP をどう捉えるか
- 接続から切断までの安全な進め方

## こんな場面で効く

アプリのログはサーバ上にしかない。  
設定ファイルを手元で直して反映したい。  
GUI のファイル共有が使えず、端末だけでやりとりする必要がある。  

こうしたとき、「SSH で入る」「安全にファイルを置く」ができれば、調査もデプロイ準備も止まらずに済みます。

:::tip[この章のゴール]

遠隔の Linux に SSH で入り、必要なファイルを安全な手段でやり取りできる状態を目指します。

:::
