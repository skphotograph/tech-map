# AWS をはじめよう

この章では、同じ `shop-api` の部品を **Amazon Web Services（AWS）** の名前と操作に落とします。  
入口は **アカウント** と AWS CLI です。  
オブジェクトは S3、仮想マシンは EC2、表は RDS、手前はロードバランサ、権限は IAM ロール、と読み替えます。

## この章で分かること

- アカウント、リージョン、AWS CLI の呼び出し元
- IAM ユーザとロール、アクセスキーをコードに置かないこと
- S3、VPC と EC2、RDS とアプリの載せ方
- 一枚の構成と、請求・ログ

## こんな場面で効く

ルートユーザのアクセスキーで日常の `aws s3 ls` を打っている。  
コンソールは東京なのに、CLI の既定リージョンが `us-east-1` で、バケットが「無い」ように見える。  
セキュリティグループで 5432 を `0.0.0.0/0` にし、RDS が世界から見える。

[よくある構成](../fundamentals/typical-architecture) の役割列に戻しながら読むと、GCP 章と二重暗記にならずに済みます。

:::tip[この章のゴール]

呼び出し元アカウントとリージョンを CLI で確認し、非公開の S3 と RDS を扱い、EC2 やアプリ基盤の線を説明できる状態を目指します。

:::
