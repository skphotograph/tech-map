# Tech Map

自分が学んだ IT 技術の整理メモを公開するサイトです。[Docusaurus](https://docusaurus.io/) で構築しています。

## セットアップ

```bash
npm install
```

## ローカル開発

```bash
npm start
```

開発サーバーが起動し、ブラウザでサイトを確認できます。変更はホットリロードされます。

## ビルド

```bash
npm run build
```

静的ファイルが `build` ディレクトリに生成されます。

## プレビュー

```bash
npm run serve
```
